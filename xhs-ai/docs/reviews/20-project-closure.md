## 2. 交付物清单（可复核）

- **功能**：Agent 对话/工具循环、DLQ 诊断→审批→重投→核验→审计竖切、知识问答（55 卡/BM25）、代码导航、HITL 状态机、模型网关、MCP 治理（27 工具/白名单/自愈/预算护栏）。
- **可靠性**：审批超时 fail-closed、跨实例决策事件、队列级消费位点核验、MCP 进程级自愈、引用硬校验。
- **证据**：MTTR 10/10（92.1% 保守下界）、KB hit@1 100%、答案级 50/50+引用 100%、红队 8 项全拦截、成本实测（18,292/1,433 tokens ≈¥0.012–0.048）、压测 P50/P95/P99、FMEA 演练 4 项。
- **文档**：reviews/01~20、reports/16+、design/12 篇专项、requirements/3 篇；简历口径 `resume-and-metrics.md`。

## 3. 显式边界（不夸大、可兜底）

1. **用户级 Token 预算/限流（F13 完整形态）未实现**：当前为单用户内测场景；已有网关侧 token 计量、工具结果截断、上下文预算（≤8K 注入）与模型降级链。多租户上线前必须补"预算计数→切 flash→只读模式"三段。
2. **MCP 工具级热替换受框架限制**：运行时重挂 client 后已注册工具不重绑（实测 `MCP client not initialized`），故采用进程级自愈（fail-fast + systemd 拉起，≈90s 全恢复）。
3. 单机测试环境，不宣称生产容量；对账/DDL 等平台侧结论以平台设计边界为准。

## 4. 可选后续（不影响结项）

- 评测集扩充（口语化问法/否定类）与向量对照实验（触发条件：hit@1 <90%）。
