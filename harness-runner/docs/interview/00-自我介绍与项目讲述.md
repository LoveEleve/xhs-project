# 自我介绍与项目讲述脚本（面试开场用）

> 原则：**数字精确、边界诚实、每段留钩子**。harness 体系是两条腿：方法论（skills 包）+ 运行时（runner），都能讲成 0→1。

## 一、90 秒总自我介绍（两项目版）

"面试官好，我是 XXX，最近两段主线：**高并发交易系统** 和 **AI 工程化落地**。

第一个是电商微服务平台：15 个 Spring Cloud 服务，我做交易与稳定性方向——事务消息 + 本地消息表、四层幂等、TCC fence，稳定性侧做过限流、DLQ 治理、对账与混沌演练（这套的追问文档我也有单独一套）。

第二个是我从 0 到 1 做的 **AI 研发流水线体系**，分两层：
- **方法论层**：harness 技能包，把'需求→编码→单测→评审→CI→部署验证'组织成 6 阶段流水线，30+ 技能、6 语言参数化，覆盖 SDD-TDD、双轴评审、软闸门；
- **运行时层**：一个 Java 引擎，把 Markdown 流程变成可执行系统——自研状态机管变更生命周期、门禁执行器真跑 `mvn`、产物与事件全程留证、LLM 阶段生成可测的验收条件。

它的核心命题是：**AI 开始大规模写代码之后，怎么保证产出可验证、可追溯、可控。** 我在一个 15 微服务的真实工程上跑通了全流程，含一次门禁红灯拦截和重试转绿。"

## 二、harness 3 分钟讲述（按链讲）

**开场定调**："这个项目我讲三条线：**为什么做**、**怎么分层**、**真跑出了什么**。"

**线1 为什么做（45 秒）**："我用 AI 写代码时最大的不安不是'写不出'，是'写完不知道对不对'：没有规格、没有门禁、没有证据，出了事连回放都做不到。所以我把工程纪律做成两层：给 AI 的**约束**（技能包）和给流程的**执行与验证**（引擎）。原则是：**人类设计约束、AI 写代码、机器验证**。"

**线2 怎么分层（75 秒）**："技能包是方法论资产：6 阶段流水线、SDD-TDD（先规格再测试再代码）、双轴评审（Spec 匹配 + 规范合规）、软闸门（存量债只减不增）、52 个占位符做 6 语言参数化，一处改全语言生效。
运行时是 6 个模块的 Java 系统：domain 是状态机（6 阶段 + 失败重试 + 断点恢复）；gate 是门禁执行器（真跑子进程，处理假死/超时/进程树）；engine 负责编排和证据链（产物版本化 + sha256 + 事件流）；llm 做需求分析阶段；app 是 CLI。存储走端口，文件仓储落地，H2 留了口。"

**线3 真跑出了什么（60 秒）**："在 15 微服务的 xhs 工程上，我跑完了 6 阶段：LLM 生成 3 条 AC → 编译 → 单测 → 评审 → CI（编译 + 覆盖率 22% 对阈值 20%）→ DONE。中间我故意注入一条失败测试，门禁直接红：`94 tests / 1 failure / exit=1`，状态机把变更置为 FAILED；删掉注入后重试 attempt=2 转绿，继续推到 DONE。整个过程 7 次阶段运行、7 个产物版本、红绿双份报告和全量日志都归档在 `evidence/d4-xhs/`。
质量上：117 个单测 + 1 个真实 Maven 集成，覆盖率门禁和测试数解析都是实测过真实工程的。"

**收尾钩子**："这套东西最有意思的部分其实是**验证本身怎么被验证**——比如我抓过自己门禁的'假绿'，您要听这个我可以展开。"

## 三、"王炸"难点清单（挑 2-3 个讲，其余等追问）

| 故事 | 一句话钩子 | 展开点 |
|---|---|---|
| 假绿 | "exitCode=0 也可能是假的——0 个测试也是绿" | 无 surefire 汇总/0 测试直接红；失败时保留失败数证据 |
| 进程假死 | "命令不结束不一定是慢，可能是管道缓冲满了" | 并发读流 + 超时强杀进程树；假死/超时/进程树三个用例 |
| 孙进程证伪 | "我以为孙进程会让我卡 4 秒，实测 49 毫秒——JDK 有 drain" | 探针 + JDK `ProcessImpl.processExited()` 源码求证 |
| JaCoCo DTD | "覆盖率报告解析失败，不是文件不存在，是 DTD 被安全策略拦了" | `load-external-dtd=false`；XXE 防护 |
| 路径穿越 | "我用 `../../evil` 探针打穿了自己的工作区" | changeId 白名单校验；探针里读到了工作区外的文件 |
| 事件粘行 | "崩溃半写的日志行会把下一条事件粘走" | 读取容忍坏行 + append 前补换行；测试抓到 |
| CI 省一次 test | "CI 阶段不跑两遍测试" | COVERAGE 命令内含 test，COMPILE+COVERAGE 组合 |
| 重启续跑 | "换一个引擎实例接着推，状态不丢" | rehydrate 一致性校验 + 原子写 + 单测 |
