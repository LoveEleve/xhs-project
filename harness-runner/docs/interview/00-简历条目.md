## 一、项目经历块（推荐写法）

**AI 研发流水线引擎（个人项目 · 0→1）** ｜ 2026.09 ｜ 独立设计与实现
- 把"需求分析→编码→单测→评审→CI→部署验证"6 阶段研发流程做成**可执行的 Java 引擎**（6 模块 Maven，158+ 单测）：自研变更状态机、门禁执行器、文件仓储与证据链、LLM 需求分析阶段、CLI 工具。
- 门禁**真跑外部构建命令**：并发读流防"命令假死"、超时强杀整棵进程树、内存截断 + 全量日志落盘；测试门禁 fail-closed（无汇总 / 0 测试 / 全部跳过一律判红）；在 15 微服务真实工程完成**门禁红灯拦截 → 修复重试转绿**演练。
- 为 AI 产出建立**可验证 + 可追溯**闭环：LLM 生成的验收条件（AC）经形式校验与**人工确认（HITL）**后放行；产物版本化 + SHA-256；事件流 SHA-256 **哈希链 + `verify` 命令**可定位篡改行。
- 自建**故障注入基准**量化门禁有效性：7 类故障 100% 检出、5 项基线零假阳性；以 **PIT 变异门禁**闭合"假测试"漏检、以**增量覆盖率门禁**（只卡 diff 变更行）治理存量债与指标博弈。
- 并发与恢复：per-change 文件锁（跨进程）+ 版本 CAS；文件原子写（tmp+ATOMIC_MOVE）；替换引擎实例可断点续跑。
- 技术栈：Java 17 / Maven / JUnit 5 / Jackson / ProcessBuilder / JaCoCo / PIT / Git / SHA-256 / OpenAI 兼容 API

**体系视角（可作第二行补充）** ：另从 0→1 建设 Harness 技能包（6 语言参数化、30+ 技能、SDD-TDD 与双轴评审），本引擎即其**运行时**。
