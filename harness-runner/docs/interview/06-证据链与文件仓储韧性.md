# 第06题 | 证据链与文件仓储：原子写、路径安全、事件日志韧性

> 难度：★★★★｜频率：★★★★｜区分度：高
> 关键词：证据包、原子写、ATOMIC_MOVE、路径穿越、JSONL、截断行、粘行、断点恢复

## 问题

问题：你的"证据链"具体存了什么？崩溃断电会不会坏？有人恶意传 changeId 呢？

## 面试可讲版（五段式）

**① 业界背景**
AI 产出要可追责，业界在讲"审计与可追溯"：SRE 的变更管理、ML 的实验追踪（MLflow）、Agent 的轨迹回放。共同点：**结构化 + 不可变 + 可搬运**。反面教材是"日志散落 + 手动截图"，出事无法复现。

**② 项目选择**
一个 change 一个目录，自包含证据包：
```
changes/{changeId}/
├── change.json        # 状态快照（status/currentStage/version/projectDir/阈值）
├── stage-runs.json    # 每次阶段执行（attempt/时间/gates 全部结果）
├── events.jsonl       # 审计事件流（append-only）
├── llm-calls.jsonl    # LLM 调用索引（模型/耗时/字符数/状态）
├── llm/               # prompt 与响应原文
└── artifacts/{type}/v{n}-*.md   # 产物（版本化 + sha256）
```
设计要点：**端口（Repository/EventLog/ArtifactStore/LlmCallStore）+ 文件实现**；产物按 `(changeId, type, version)` 只增不改；整个目录拷走即可作为证据归档（`evidence/d4-xhs/` 276KB 就是一次完整演练）。

**③ 坑（全部是探针/测试抓出来的）**
- **路径穿越**：changeId 直接 `resolve()` 进路径，`../../evil` 能读写工作区外文件——**我用探针真的读到了工作区外的 change.json**，修复：白名单校验 `[A-Za-z0-9_-]{1,64}`；
- **非原子写**：`Files.writeString` 中途崩溃会留半文件（状态就没了）→ tmp + `ATOMIC_MOVE`；
- **截断行**：崩溃会把 JSONL 最后一行写一半，读取直接抛异常把 `status` 打崩 → 读取容忍坏行；
- **粘行**（更深一层）：截断行没有换行符，下一条 append 会跟它粘成一行、一起被吞 → append 前检测残尾补换行（**这个是测试抓出来的**）。

**④ 兜底**
- 审计哈希链（防篡改）✅ 已实现（D5.7）：事件 SHA-256 链式哈希 + `verify` 命令；边界：整链重写需外锚（SCM/WORM/TSA/签名）；
- 多写者并发没锁（单机语义），靠 DB 适配器兜（设计）；
- 完整性：产物有 sha256，但当前没有跨文件全量校验清单（设计）。

**⑤ 话术**
> "证据链的目标是'拷走一个目录就能复盘一次变更'。我专门用探针打过自己：`../../evil` 能越界读文件，修成白名单；还处理了原子写、日志截断和粘行——这些不是理论，是测试和探针逼出来的。"

## 追问与参考回答

**追问1：为什么不用数据库存？** 定位单机零依赖 + 证据可搬运；目录天然可归档、可 diff、可读。代价是无聚合查询/并发，H2 适配器是演进路径。
**追问2：为什么产物用版本号而不是覆盖？** 证据要可对比：红/绿两次执行的报告并排看才有价值（xhs 演练里 `v1-test_design.md` 红、`v2-test_design.md` 绿）。
**追问3：sha256 用来干嘛？** 内容寻址/防篡改的第一步；产物被改能发现。全量校验清单与链式哈希是下一步。
**追问4：events.jsonl 和 stage-runs.json 不是重复吗？** 职责不同：stage-runs 是权威执行记录（含 gates 全量），events 是时间线审计（谁在什么时候把状态推到哪）。回放/统计用 events，判定/对账用 stage-runs。
**追问5：断电在 append 和 move 之间呢？** move 前有 tmp 文件（残留但无害，读取忽略），原文件仍是旧版本完整内容——这就是 ATOMIC_MOVE 的意义。

## 面试官评分点

**高级开发级**：能画出目录结构；知道原子写、路径校验、JSONL 容错三类问题。
**架构师加分**：证据包视角（可搬运/可对比/可审计）、端口与演进、探针驱动修复（路径穿越那个故事）。
**危险信号**：把用户输入直接拼路径；`File.write` 当原子操作；崩溃恢复没概念。
