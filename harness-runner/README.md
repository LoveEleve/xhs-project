# harness-runner

> 把 Markdown 形态的 AI 研发流水线（Harness Engineering）做成可执行的 Java 系统。

**一句话**：给 AI 编码装一条"流水线 + 质检线"——把"AI 在聊天框里生成代码"变成"可编排、可验证、可追溯的交付流程"。

**状态**：规划阶段（v0.1）
