# 测试用例: 订单拆单与行级售后改造

> 机器可读的迭代协议产物之一。TC 编号归属 AC，供 test/report.md 与 harness-quality 的 flow→test 对账使用。

## 用例清单

| TC | 归属 AC | 前置条件 | 输入 | 期望输出 | 自动化 |
|----|---------|---------|------|---------|--------|
| TC-1 | AC-1 | 2 商家 SKU fixture | 下单（2 商家 3 行） | 1 父单 + 2 子单 + 3 行；父实付=Σ子=Σ行 | 是 |
| TC-2 | AC-1 | 同上 | 行插入失败（注入异常） | 整体回滚（父/子/行/本地消息均无） | 是 |
| TC-3 | AC-2 | 订单 300 优惠 30 | 分摊落库 | Σshare=30（分单位）；行实付=明细−share | 是 |
| TC-4 | AC-2 | 同上 | 部分退（1/3 件）再退满 | 累计退款=行实付（退满补齐） | 是 |
| TC-5 | AC-3 | 已完成订单 | 售后申请（同 item 同类型重复） | 唯一键拒绝；不同 item 互不影响 | 是 |
| TC-6 | AC-3 | 同上 | 三道闸门（0 可退/SKU 累计/父单累计） | 各自异常码 | 是 |
| TC-7 | AC-4 | 子单状态组合表 | computeParentStatus（穷尽） | 按 AC-4 规则取值（含混合终态→3） | 是 |
| TC-8 | AC-5 | 已付款订单 | 部分子单发货 | 子单→2；父单→2（全部发货后） | 是 |
| TC-9 | AC-5 | 待付款订单 | 用户取消 | 父+全子同事务→4；终结事件驱动副作用 | 是 |
| TC-10 | AC-6 | 订单在 1/2/3 | 部分退款 | 父单不动；行/子单按退款收敛 | 是 |
| TC-11 | AC-6 | 订单在 1/2/3 | 累计全退 | 父→5 且全子→5（status=2 缺口修复） | 是 |
| TC-12 | AC-7 | 全仓 | 全量重编测试（删 test-classes） | 四模块全绿 | 是 |
| TC-13 | AC-7 | 竞态场景 | 支付回调 vs 关单 / 聚合并发 / 重复消息 | 幂等收敛（无重复副作用） | 是 |
| TC-14 | AC-8 | SKU 挂 seller | 下单映射 + 分组 | sellerId 下发；按 seller 分组正确 | 是 |
| TC-15 | AC-9 | 订单详情/列表 | 查询 | 父/子/行各一次批量查询（无 N+1） | 是 |
| TC-16 | AC-10 | 改造完成 | 文档检查 | 修订记录 + wiki 更新齐备 | 否（手工） |
