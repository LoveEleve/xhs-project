# 动态事实来源

> 本项目稳定上下文进 Git，**动态事实**从权威系统经 MCP/CLI 实时查询，两者在 Agent 执行时汇合。
> 本文件声明各类动态事实的来源与连接方式，供 Owner Agent / deploy-verify / test 技能按需调用。

## 事实来源清单

| 事实类型 | 权威系统 | 连接方式（MCP / CLI / HTTP） | 使用场景 |
|---------|---------|------------------------------|---------|
| 工作项状态 | <如 Jira/Aone/禅道> | <MCP 工具名 / CLI 命令> | 发布后回查工作项状态、需求排期 |
| 测试环境 | <环境平台> | <…> | deploy-verify 冒烟前确认环境可用 |
| 日志 | <日志平台/CLI> | <…> | 排障、traceId 检索 |
| 数据库 | <DB 客户端/MCP> | <…> | 数据核对、迁移验证 |
| 配置中心 | <Apollo/Nacos/…> | <…> | 读取运行时配置、确认生效 |
| 指标监控 | <监控平台> | <…> | 发布后观测 |

## 连接约定

- 优先用已有的 MCP 工具；无 MCP 时降级为 CLI/HTTP 命令，命令统一登记在 `.harness/scripts/`。
- 凭证与密钥不落 Git，经环境变量 / 密钥管理注入。
- 查询失败时如实标注「动态事实不可得」，不臆造；必要时转人工验证。

## 使用时机

| 阶段 | 查询的动态事实 |
|------|---------------|
| 需求分析 | 工作项状态、历史同类需求 |
| 测试 | 测试环境状态、数据库基线 |
| 部署验证 | 环境健康、日志、指标 |
| 发布后回查 | 工作项状态、协同状态（见 harness-ship） |
