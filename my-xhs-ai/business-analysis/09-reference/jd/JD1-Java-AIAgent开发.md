### 岗位职责
- 搭建具备任务处理、工具调用、记忆管理等核心能力的智能体（AI Agent）系统；
- 设计并开发模块化、可组合的 Agent 架构，支持子模块的灵活调度与协作；
- 集成外部工具（如网页操作、接口调用、搜索引擎等），提升 Agent 的任务执行效率与适应性；
- 应用 RAG（检索增强生成）等技术手段，提升回答的准确率与信息完整性；
- 优化系统性能，确保在高并发场景下的稳定性与响应速度。

### 岗位要求
- 本科及以上学历，计算机、软件工程或相关专业背景；
- 熟练掌握至少一门编程语言（如 Python、Java），具备良好的编程实践能力，熟悉云服务平台和容器化部署工具；
- 理解大语言模型的调用机制，具备良好的 prompt 编写能力，了解主流 AI Agent 框架的设计理念；
- 具备良好的系统设计能力，代码结构清晰，逻辑严谨，便于维护与扩展；
- 有以下相关经验者优先：多智能体协作（Multi-Agent）、外部工具链调用（Tool Use）、记忆模块设计与实现等。

### 加分项
- 对 AI Agent 类产品有研究，有自己的思考总结；
- 有成长心态，对"模糊"有一定的包容性；
- 有海外工作、学习经历，对欧美主流的 AI Agent 产品有深入研究。
