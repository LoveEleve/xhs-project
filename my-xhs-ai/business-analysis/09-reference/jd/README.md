## 二、协议层信号（JD15 关键转折）

**JD15（Agent 框架研发）** 首次把 **MCP + A2A + FunctionCall** 三协议并列，并点名 **ReAct / PlanAct / CodeAct** 范式。
- **MCP**：我们已定为工具集成协议（ADR-003）。
- **A2A**：Agent 间通信协议，我们此前只放 L7 选修 → **建议更早了解**（协议层趋势）。
- **FunctionCall**：LangChain4j 原生支持，即用。
- **PlanAct / CodeAct**：Agent 执行范式，可补进概念词典。

---

## 三、向量数据库选型（JD17 新信号）

JD17 明确要求实操 **Milvus / FAISS / Chroma / PGVector**，且强调 RAG 全链路（解析→分段→向量化→检索→重排→上下文增强）。
- 我们技术栈是 **ES 8.12.2 的 knn 向量检索**，理念一致（都是 embedding 检索）。
- **决策点**：ES knn 已够用；如需"向量库"加分项，可评估 **Milvus** 作对比/第二实现。

## 四、三工程概念（JD17 提出）

**提示词工程 / 上下文工程 / 约束工程** 三工程并列。
- 提示词工程、上下文工程 → 概念词典已有。
- **约束工程（guardrails/输出约束）** → 需补进 `concepts-glossary.md`（呼应幻觉治理）。

## 六、就业建议（对用户）

1. **Java 可投 10/18**——不必转 Python，Java 有真实 Agent 岗位面。
2. 核心卖点组合：**Java + LangChain4j + MCP + RAG + 真实业务（my-xhs）落地案例 + 可观测/可追溯/评估体系工程化**。
3. 学习重点升级：**微调（LoRA/SFT/RL）**、**多智能体**、**向量数据库**、**效果评估体系**。
4. 差异化：绝大多数候选人只有 demo，**你有 my-xhs 真实业务 3 能力面落地 + D0 审计 + 工程化**，这是核心差异。JD18 明确"仅聊天机器人/简单 RAG/开源 Demo 不符合专家级要求"——印证走真实业务是对的。
