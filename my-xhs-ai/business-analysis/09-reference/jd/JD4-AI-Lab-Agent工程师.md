## JD 原文

**写在开篇**：我们正在找一位同频的工程师，加入 AI Lab 核心团队，一起把前沿的 Agent 技术，从原型想法变成能服务海外千万用户的真实产品。我们不太纠结你过去的 Title 是全栈、后端、前端还是 AI 研发，更关心你是不是那个"能用代码把 AI 想法落地、愿意折腾新东西"的人。比起完美的履历，我们更想看你 **GitHub 上的个人项目**、一段为了解决问题写的自动化脚本、或是一个你亲手调通的 Agent 小工具。如果你也这样，我们大概率能聊得来。

### 岗位职责
- 加入 AI Lab，既参与前沿 Agent 技术的原型验证与创新探索，也负责面向海外 C 端用户的 AI Agent 生成平台全链路开发；
- 参与**多智能体系统核心模块**实现，包括规划、推理、工具调用、智能体编排等关键环节，用代码验证技术可行性并落地为可用功能；
- 搭建**高性能 RAG 系统**、优化提示词策略，聚焦海外 C 端用户体验，解决高并发场景下的系统稳定性问题；
- 可根据你的擅长方向，侧重负责平台后端架构、或是前端核心交互开发，无需强制全栈通吃；
- 探索 Agent 技术前沿玩法，把创新想法快速转化为可演示的产品功能，推动从 0 到 1 的落地验证。

### 岗位要求
- 掌握 Python/Go/**Java**（后端）或 React/Vue（前端）至少一门技术，有扎实的编码能力和基础工程化思维；
- 对 LLM、RAG、Agent 等 AI 技术有自发的好奇心，哪怕只有相关的个人项目、小工具开发经验完全可以聊；
- 具备基础的产品思维，能理解用户需求，愿意为最终的落地结果负责；

### 最重要的要求
- 请准备好 **1-2 个你亲手做过的 AI 相关项目**，可以是用 API 搭建的小工具、调优过的 RAG 系统、尝试开发的 Agent 脚本，面试时我们希望先聆听你的项目经历。

### 加分项
- 有从 0 到 1 主导或深度参与 AI 产品核心模块（智能体编排、RAG 系统、多智能体协作）并成功上线的经验；
- 熟悉 LangChain/Dify 等主流 AI 开发框架，拥有低代码平台二次开发经验；
- 拥有海外 To C 产品开发经验，熟悉海外用户使用习惯；
- 具备高并发场景下系统性能优化经验，或是全栈开发能力。
