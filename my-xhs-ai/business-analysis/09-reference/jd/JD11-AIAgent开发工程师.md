### 岗位职责
- 参与 AI Agent 产品需求分析与架构设计，承担核心功能模块开发、调试与迭代，保障系统稳定可用。
- 依托 **LangChain / LangGraph / AutoGen / Dify** 等开源框架与平台搭建智能 Agent 体系，实现**工具调用、多步骤推理、长期记忆、任务拆解**等核心能力。
- 负责 **RAG 全链路搭建与优化**：文档解析、向量库搭建、检索策略调优、提示词工程优化，提升回答精准度。
- 负责 Agent 应用工程化部署、**Docker/K8s 容器封装**、接口开发与性能调优，适配**高并发**场景。
- 对接业务部门，将 Agent 落地至**客服、数据分析、流程自动化、知识库问答**等场景。
- 跟进大模型、AI Agent 前沿技术与行业方案，开展技术调研与 **POC 验证**。
- 撰写技术文档、开发规范、测试用例；协同测试、运维完成联调、故障修复。
