## JD 原文（节选核心）

### 岗位职责
- 深度参与 **Agent 开发平台 / 核心产品整体技术架构**搭建，负责产品从 0 到 1 以及 1 到 N 的迭代演进。
- 设计**企业级 Agent 框架**，沉淀**可复用工具集、记忆系统、沙箱系统、调度引擎、评测体系**。
- 负责复杂业务场景下的 Agent 整体方案设计。
- 推动**多智能体协作、长期记忆、自主规划**等前沿能力落地工程化。

### 任职要求
- 5 年以上软件开发经验，2 年以上大模型 / Agent 应用架构设计经验；
- 完整主导过至少一套 Agent 系统从架构设计到上线全流程，具备规模化落地实战案例；
- 深入掌握 Agent 核心组件：**规划器 Planner、执行器 Executor、记忆模块（短期/长期/情景记忆）、工具调用、反思机制 Reflection**；
- 精通主流大模型与开源 Agent 生态，可结合业务场景完成**技术选型与组合适配**；
- 熟悉 **Agent 安全管控、幻觉抑制方案、可观测体系搭建（链路追踪 Tracing / 日志 Logging / 指标 Metrics）**；
- 优秀系统架构设计能力，擅长**高并发、低延迟、高可用**系统设计，了解分布式系统。

### 加分项
- 熟悉 openclaw、hermes、openhuman 等主流 Agent 项目架构；
- 拥有 **Agent 评测基准 Benchmark** 设计经验，了解 **AgentBench、GAIA、SWE-bench** 等评测体系。
