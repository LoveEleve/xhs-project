## JD 原文

### 为什么有这个岗位
我们希望把 AI 落到真实业务，而不是停留在 Demo。你的工作将直接服务真实用户与真实业务场景。

- 建立评测集和核心指标

- 3 年以上 **Python** 开发经验
- 有真实上线的 LLM / Agent / RAG 项目经验
- 熟悉 API 集成、状态管理和评测优化

### 为什么加入我们
- 你的代码将持续运行在真实业务中，并直接影响产品能力。
