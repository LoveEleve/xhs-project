## JD 原文（节选核心）

### 项目背景
红杉中国核心人才项目，输送潜力青年至红杉生态前沿科技企业；岗位归属**企业级低代码 + 智能协作平台**团队，将大模型与 Agent 能力深度融入低代码产品，让中小企业用户通过自然语言搭建业务系统、自动化工作流。招聘兼具 **AI Agent 技术能力 + 熟悉企业真实业务场景**的复合型人才。

### 你的角色与工作内容
- **Agent 应用层开发**：面向中小企业多场景（CRM、进销存、项目协作、审批流程、财务报表等）设计开发 AI Agent 功能模块；**侧重上层产品功能落地，不做底层大模型研发**。
- **场景理解与需求拆解**：挖掘中小企业痛点；把模糊口语化需求（如"用 AI 自动跟进客户"）拆解为可落地的 Agent 工作流：**意图识别→数据查询→动作执行→结果反馈**。
- **Prompt 工程与工作流编排**：设计 Prompt 模板与 Agent 编排逻辑，保障输出准确、稳定可控；能**规避、抑制 AI 幻觉**。
- **产品共建与快速迭代**：与产品经理、前端协作，站在用户视角衡量体验，不只限技术开发。

### 任职要求
- 扎实技术基础：计算机相关专业；熟练掌握 **Python / Go / Java 任意一门后端语言**，有真实 API 开发经验。
- **Agent 落地实战经验**：熟练使用主流 Agent 框架（LangChain、Coze、Dify 等）；理解 **ReAct、Function Calling、RAG**；要求**真实业务场景落地项目经历，而非仅运行教程 Demo**。
- **业务感知能力（硬性要求）**：并非纯算法岗位；需了解企业日常经营运转（销售、采购、库存、人事、财务等基础业务），可顺畅和非技术客户沟通。
