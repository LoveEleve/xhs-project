## JD 原文（节选核心）

### 岗位职责
- 参与天猫超市 B 端经营 Agent 系统整体设计、编码、测试与上线全流程。
- 将大模型及各类 AI 模型接入 Agent 系统，完成业务任务与功能开发。
- 负责 **Agent 核心模块研发：工具调用、记忆机制、规划推理、环境交互**；持续优化性能、稳定性与可扩展性。
- 对接运营、产品、算法，把 Agent 落地于**电商 B 端定价、商品管理、招商**等真实业务场景。
- 跟进 AI Agent 前沿技术并落地到产品迭代。

### 职位要求
- 熟练使用 **Python、Java**；掌握异步编程、并发、性能优化；了解电商 Web 框架与后端架构。
- 理解 LLM 基础原理、推理逻辑；调用过主流大模型 API。
- 熟悉 **Agent 架构范式、工作流编排、ReAct、多智能体协作**；了解 LangChain 等框架；掌握**向量数据库、Embedding**；知晓 **LoRA、SFT、强化学习**等微调方式；了解 **Agent 训练优化、性能评估、安全风控与异常容错**。
- 热爱 AI，擅长问题拆解与系统性思考，能在需求模糊环境下自主推进。

### 加分项
- **Agent 线上落地实战项目经验**；LLM 微调、模型部署；强化学习、任务规划算法；开源贡献/技术博客/竞赛。
