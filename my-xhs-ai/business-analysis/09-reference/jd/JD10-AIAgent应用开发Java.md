- **了解 MCP 标准、流式传输协议（SSE / Streaming HTTP）**

- 熟练掌握 Java（Python 亦可）

4、加分项：Vue/JS 前端基础；**AI + 业务落地项目经验**；大模型平台搭建、Agent 框架封装经验。
