# 支柱一：内容与社交 — 总览

> 业务定位：平台的**内容护城河**——用户创作、互动、社交关系与内容分发。AI 在此支柱的价值是**内容健康度、互动增长、分发效率的指标与诊断**。
> 覆盖服务：content-social、home(BFF)、search/recommend、counter、notification、im、analytics。

## 业务问题清单（AI 应能回答）

| 业务问题 | 类型 | 就绪度 |
|---------|------|:---:|
| 今天发布多少新笔记？审核通过率？ | 指标 | ⚠️ |
| 哪些话题最热门？互动最高的笔记？ | 指标 | ✅ |
| 互动率（赞/藏/评/分享）趋势 | 指标 | ✅ |
| 粉丝净增长 / 增长最快用户 | 指标 | ⚠️ |
| 内容互动/增长异常（为何某时段互动骤降） | 诊断 | ⚠️ |
| 热搜 Top20 / 搜索无结果率 / 推荐 CTR | 指标 | ✅/⚠️ |
| 通知/推送失败、私信积压 | 诊断 | ✅ |

## 核心业务循环
```
创作者发布笔记 → DFA审核 → 上架 → Feed 曝光 → 用户互动 → 异步计数 → 通知 → 回流
                ↑                                    ↘
                草稿/编辑                              搜索/推荐 发现
```

## 关键不变量（本支柱）
1. 笔记公开可见 = `status=发布 AND is_deleted=0`。
2. 计数异步：Redis 权威、MQ 落库、对账修正。
3. 关注/点赞/收藏存 Redis（ZSet/Set），**非持久化事件流水**。
4. Feed：大V拉取(outbox) + 小V推送(inbox)。

## 数据就绪度汇总
| 数据 | 就绪度 | 缺口 |
|------|:---:|------|
| 发布/审核 | ⚠️ | 缺独立 published_at/audited_at |
| 互动计数 | ✅ | — |
| 粉丝净增长 | ⚠️ | Redis 非事件流水 |
| 搜索/热搜 | ✅ | — |
| 推荐 CTR | ⚠️ | 需曝光数据 |
| Feed 分发 | ⚠️ | 需曝光→互动漏斗 |
