# 互动与计数（点赞/收藏/评论/分享）

## 业务问题（AI 能回答）
- 互动率（赞/藏/评/分享）趋势与分布。
- 互动最高的笔记/话题、互动异常波动。
- 计数一致性（Redis vs MySQL 漂移）。

## 口径与定义
- **互动计数类型**：1=点赞 / 2=收藏 / 3=评论 / 4=分享 / 5=浏览；targetType 1=笔记 / 2=用户。
- 点赞/收藏：`bizType 1=笔记 2=评论`（收藏只作用于笔记）。
- 计数异步：MQ 事件 → Redis INCR → Buffer 攒批 → batchUpdate MySQL t_counter。

## 数据来源与就绪度
| 指标 | 来源 | 就绪度 |
|------|------|:---:|
| 点赞/收藏/评论/分享/浏览数 | t_counter + Redis myxhs:counter:* | ✅ |
| 互动率（对曝光） | 计数 ÷ 曝光 | ⚠️ 需曝光数据 |
| 计数漂移 | 对账 | ⚠️ 需观测 |
| 单条点赞去重 | Redis like:set | ✅ |

## 关键不变量 / 可信边界
- **计数权威在 Redis，MySQL 兜底，对账以 MySQL 为准修正 Redis**。
- 点赞/收藏幂等（SADD + 5s 幂等）；1 分钟限流 30 次。
- 互动计数与 Feed 递送分离（不同消费者）。

## 关联诊断
- "某笔记/某时段互动骤降" → 需区分：内容质量问题 vs 分发/计数链路异常 vs 系统降级。计数对账接口可核对漂移。
