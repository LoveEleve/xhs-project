# 用户身份与安全（登录/Token/账号）

## 业务问题（AI 能回答）
- 日注册/登录、登录成功率、活跃度。
- 登录失败/账号锁定趋势（异常爆破检测）。

## 口径与定义
- **认证状态机**：未认证 →(验证码+登录)→ 已认证；Token 过期/刷新/登出/改密（全部失效）。
- **Token 生命周期**：access(30min) + refresh(7d)；单设备登录踢旧 token 入黑名单。
- **登录锁定**：密码错 5 次 → Redis lock TTL 15min。
- **验证码**：一次性（GETDEL 原子消费），5min 过期。

## 数据来源与就绪度
| 指标 | 来源 | 就绪度 |
|------|------|:---:|
| 日注册/登录成功率 | t_user + 登录日志 | ⚠️ 需汇总 |
| 登录失败/锁定 | Redis login:fail/lock | ⚠️ Redis 易失 |
| DAU/MAU | t_user + 活跃日志 | ⚠️ 需汇总投影 |
| 屏蔽规模 | Redis Set | ⚠️ 非持久化 |

**缺口**：登录失败/锁定计数存 Redis，**易失、无持久事件流水** → 异常爆破的长期趋势/归因受限。若要做登录安全诊断，需补登录事件流水。

## 关键不变量 / 可信边界
- 用户名/手机号唯一；BCrypt 密码；改密后全 Token 失效。
- 地址上限 20、首个自动默认；归属校验（他人地址 FORBIDDEN）。
- 不能屏蔽自己；改资料用延迟双删。

## 关联诊断
- "登录成功率异常/爆破" → 需登录事件流水 + IP/设备维度（当前缺）。
