# ADR-002：LLM/Agent 核心框架

- **状态**：✅ 已接受（2026-08-10，主框架已定 LangChain4j）
- **背景**：候选 LangChain4j vs AgentScope Java 2.0。
- **决策**：**V1 主框架 = LangChain4j Core**。理由：成熟、招聘主流、无 Boot 3.2.5 冲突、生态大；Harness（权限/HITL/会话/预算）由我们手写以掌控边界（符合安全模型 + 学习/作品价值）。
- **保留**：AgentScope Java 2.0 为**验证替代**——其权限/HITL/会话贴合度高，若后续同场景 PoC 证明显著更优再切，**不阻塞 D1**。
- **约束**：两框架都不应迫使升级 Spring Boot 3.2.5；用 OpenAI-compatible 模块（对接火山方舟）。
