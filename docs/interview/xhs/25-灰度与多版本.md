# 第25题 | 灰度、多版本与压测染色

> 难度：★★★☆☆｜频率：★★★☆☆｜区分度：中
> 关键词：TrafficColoring、GrayRoute、@ApiVersion 替换 HandlerMapping、灰度打标、版本降级

## 问题
灰度发布怎么做？多版本 API 怎么兼容？压测流量怎么和生产隔离？

## 面试可讲版（五段式）

**① 业界背景**
灰度三层：**流量标记**（谁进灰度）→ **路由规则**（灰度流量去哪）→ **多版本共存**（新旧接口兼容）。关键坑：标记要能跨服务透传（HTTP header/MQ 属性），路由要可回滚，版本要能降级（未知版本走默认而不是拒绝）。

**② 项目选择**
- **标记**：`TrafficColoringFilter`（网关第一层）给请求打灰度/压测标记，放 header；Feign 拦截器 + MQ 生产者把标记透传到下游与消息（traceId 同链路）；
- **灰度路由**：`GrayRouteFilter`——**按用户哈希 10% 打标**；当前实现是**只打标 + 记录**，实例级过滤未启用（诚实边界：灰度发布链路未闭环，是"标记就绪"状态）；
- **多版本 API**：`@ApiVersion` 注解 + 自定义 `RequestMappingHandlerMapping`——按 Header 版本（默认 v1）路由到不同方法；
  - test-4 实测：v2/v9/无版本均 200；**非 v1 版本记录日志并降级（不拒绝）**——未知版本走 v1，保证旧客户端不挂；
- **压测染色**：压测流量带标记 → `ShadowTableInterceptor` 自动改写影子表，实现压测与生产数据隔离。

**③ 坑**
- **灰度标记透传不全**：HTTP 透传了但 MQ 消息没带 → 异步链路回不到灰度实例；必须生产者/消费者双向处理；
- **版本路由与网关版本过滤顺序**：网关做粗粒度（v1 默认/未知降级），服务内做细粒度（@ApiVersion）；两层语义要一致；
- **"灰度=已实现"是危险表述**：`GrayRouteFilter` 只打标，不能对外说"灰度发布上线了"——要讲清"标记链路已通、实例过滤未启用"；
- **压测标记泄露**：压测标记进了生产消息会被下游当生产流量处理——网关入口做白名单/过滤。

**④ 兜底**
- 未知版本降级为 v1（不拒绝），旧客户端兼容；
- 灰度可开关（filter 可禁用），出问题回滚标记规则；
- 版本兼容承诺：新增字段不删旧字段、枚举扩展兼容；
- 观测：灰度标记日志 + 版本分布指标。

**⑤ 话术**
> "灰度我们分三层：网关 TrafficColoring 打标、Feign 和 MQ 透传、GrayRoute 按用户哈希 10% 打灰度标记——但要诚实说，当前实例级过滤还没启用，是'标记就绪'状态。多版本 API 用注解替换 HandlerMapping，v2/v9/无版本都实测 200，未知版本降级走 v1 而不是拒绝，保证旧客户端不挂。压测流量走同一套标记 + 影子表隔离。"

## 追问与参考回答
**追问1：灰度流量怎么保证全链路？** 标记在入口产生，HTTP header + MQ header 双向透传；任何一跳丢失都会导致链路串回生产版本。
**追问2：为什么未知版本降级而不是 400？** 移动端版本滞后严重，拒绝会让老用户不可用；降级 + 日志 + 指标是渐进式升级的正确姿势。
**追问3：灰度实例过滤怎么做？** 网关/负载均衡按灰度标记过滤实例（在实例列表上按 metadata 筛）；本项目这一层未实现（诚实说明）。
**追问4：压测标记怎么防止污染生产？** 入口严格白名单（内网来源）+ 标记不进真实 MQ（或消费端丢弃）+ 影子表隔离。
**追问5：多版本和 API 网关什么关系？** 网关做版本路由的粗粒度（按 header 转发不同服务/实例），服务内做方法级细粒度；两者语义要统一。

## 发散追问地图（横向）
- 发布策略：金丝雀/蓝绿/灰度/AB、流量比例与回滚。
- 流量标记：header 透传、全链路染色、Mesh（Istio）灰度。
- 版本管理：语义化版本、兼容策略（新增不删/枚举扩展）、契约测试。
- 压测隔离：影子表/影子库、染色流量、Mock 下游。
- 网关：路由规则动态化（Nacos/DB）、灰度规则热更新。

## 面试官评分点
**高级开发级**：能讲灰度三层；知道标记要全链路透传。
**架构师加分**：未知版本降级策略；灰度"只打标"的诚实边界；压测染色与影子表联动；版本兼容契约。
**危险信号**：把打标说成灰度已上线；未知版本直接拒绝；标记不透传 MQ。

## 本项目真实证据
- `GrayRouteFilter`（按用户哈希打标；注释明确实例过滤未实现）、`TrafficColoringFilter`、`ApiVersionFilter`（v1 默认，未知版本记录日志+降级）；
- `@ApiVersion` + HandlerMapping 替换；test-4：v2/v9/无版本均 200；
- `ShadowTableInterceptor` 压测染色影子表；Feign/MQ 标记透传实现。

## 版本与来源
本项目网关/服务版本路由代码与 test-4 运行记录；灰度发布公开实践。

## 真实性说明
打标/版本路由/降级为代码与实测事实；"实例过滤未实现"为诚实边界；无"灰度已全量上线"表述。
