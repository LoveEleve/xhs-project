# 第16题 | 可观测与告警

> 难度：★★★☆☆｜频率：★★★★☆｜区分度：中
> 关键词：17 个 ai_* 指标、告警规则、traceId、评测报告、排障闭环

## 问题
Agent 怎么观测？出问题怎么定位？有哪些指标和告警？

## 面试可讲版（五段式）

**① 业界背景**
Agent 可观测比微服务难：链路长（多轮 LLM+工具）、输出非确定、成本敏感。指标要覆盖：**流量**（会话/轮次）、**延迟**（首字/整轮）、**错误**（模型/工具/审批）、**成本**（Token/预算）、**健康**（MCP 进程）。日志要能串链路（traceId），评测结果也是"可观测"的一部分。

**② 项目选择**
xhs-ai 可观测体系：
- **17 个 `ai_*` 指标**：`ai_agent_runs_total`/`ai_agent_duration_seconds`/`ai_tool_calls_total`/`ai_tool_errors_total`/`ai_model_calls_total`/`ai_model_latency`/`ai_model_tokens_total`/`ai_model_budget_total`/`ai_model_breaker_open_total`/`ai_approval_*`/`ai_mcp_health`/`ai_mcp_restarts_total`/`ai_retention_deleted_total`/`ai_agent_tool_schema_tokens`/`ai_agent_tools_total` 等；
- **告警规则**：基于上述指标（审批积压/回收、熔断打开、MCP 健康、预算等）；
- **traceId 全链路**：请求 ID（X-Request-Id）贯穿 Agent→模型→工具→审批→审计；
- **评测即观测**：工具选择 12/12、KB hit@1 100%、答非所问拒答等评测报告入库，回归可跑；
- **排障闭环**：结论可回链（traceId → 审计 → 原始工具结果）。

**③ 坑**
- **首字延迟没采数（诚实缺口）**：流式场景用户最关心首字延迟，当前未采（生产化缺口第 18 题）；
- **指标基数爆炸**：不要用 sessionId/traceId 做标签；用用户/工具/模型等有限维度；
- **告警风暴**：同一根因多指标告警→关联/静默；本项目对 MCP 健康采用"仅告警不自动重启"；
- **日志与指标割裂**：要能从指标跳到日志/审计（traceId 打通）。

**④ 兜底**
- 指标 + 日志 + 审计三源可互跳（traceId）；
- 告警规则覆盖关键故障（熔断/审批积压/MCP）；
- 评测门禁（评测不过不发版）；
- 数据保留：`ai_retention_deleted_total` 记录清理。

**⑤ 话术**
> "Agent 可观测我铺了 17 个指标：流量、延迟、工具错误、模型调用、Token/预算、熔断、审批、MCP 健康和保留清理；告警基于这些指标做。链路用 X-Request-Id 贯穿 Agent→模型→工具→审批→审计，结论能回链到原始证据。评测报告也算可观测的一部分，工具选择 12/12、KB hit@1 100% 都是回归门禁。首字延迟目前没采数，这是明确缺口。"

## 追问与参考回答
**追问1：Agent 的 SLO 怎么定？** 可用性（成功率）、延迟（首字/整轮 P95）、质量（评测通过率）、成本（每会话 Token）；本项目评测门禁 + 延迟指标为主，首字待补。
**追问2：为什么不做分布式追踪？** 有 traceId 贯通 + 审计回链，够当前用；OTel 接入是生产化缺口（第 18 题）。
**追问3：指标标签怎么选？** 有限基数：工具名/模型名/角色/状态；绝不带 sessionId。
**追问4：告警怎么防风暴？** 关联规则 + 抑制 + 静默；自愈动作限频（第 13 题 NRestarts=24 教训）。
**追问5：怎么用指标定位"答得不好"？** 指标定位链路（模型/工具/预算），质量用评测；两者结合。

## 发散追问地图（横向）
- 可观测三支柱：指标/日志/追踪；OTel 标准。
- LLM 观测：Token/成本、Prompt/响应采样、评测、用户反馈。
- 告警工程：规则设计、抑制、值班、SLO burn rate。
- 排障：traceId、审计回链、复现工具。
- 隐私：日志脱敏（第 12 题）、保留策略。

## 面试官评分点
**高级开发级**：能列 Agent 关键指标；知道 traceId 贯通。
**架构师加分**：指标基数控制；评测即门禁；主动披露首字延迟缺口；告警防风暴与自愈限频联动。
**危险信号**：只监控 QPS/RT；指标带高基标签；无成本/质量观测。
