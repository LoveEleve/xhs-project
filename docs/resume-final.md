## 项目一 · 小红书电商交易平台（15 微服务 / 8 类中间件）
> 定位：成熟交易系统的**一致性治理与稳定性优化**（优化项目口径），主导高价值攻坚并沉淀可复现验证体系。
> 关键词：分布式一致性、消息治理、性能容量、容灾演练

- **交易一致性体系落地**：自研库存 TCC + Fence（空回滚/悬挂/幂等三异常，**11 个场景实测通过**）；订单链路"事务消息 + 本地消息表 + **75s 回查**"杜绝半消息悬挂；设计 **8 个对账/修复 Job**（库存/券/购物车/未读/关注/本地消息/超时关单/订单映射）兜底最终一致，修复动作幂等可重放。
- **消息治理与死信清零**：定位并修复多组历史死信根因（事件流水无 SKU 动作落库失败、索引消费者韧性缺陷等），平台 `%DLQ%*` 积压**清零**；为消费者补齐**失败分类**（可重试 vs 确定性失败）与**版本幂等**（ExternalGte/冲突跳过）；把死信监控从硬编码 22 组修正为对齐实际 **26 个消费组**，修复"指标恒为 0"的算法缺陷。
- **性能与容量基线**：压测建立服务级容量基线（商品 **1020** / 笔记 **1096** / 首页 **764** / 推荐 **761** / 搜索 **683** RPS；搜索 **P50 29ms / P99 96ms**）；按实测校准网关分级限流；**6 秒慢下游注入下首页按 200 QPS / 2s 超时受控降级**。
- **容灾与稳定性演练**：Redis Sentinel **failover 2.3s** 完成且数据无损、会话无错乱；Elasticsearch 停机演练受控降级（检索类报错不拖垮服务）；沉淀混沌演练脚本与复盘。
- **全链路可观测与工程治理**：traceId 跨 HTTP/MQ/长连接透传；ELK + Prometheus + SkyWalking 全链路；**117 项测试矩阵 + 21 个运行态问题**修复闭环；Maven Enforcer 依赖收敛（重复类/版本漂移清零）。
- **边界（主动写）**：对账与在线写无屏障（收敛历史差异，不保证实时一致）；订单分片 4×4 无 rehash 方案，扩容是已知短板（正解双写迁移/基因分片）。

## 项目二 · 小红书 AI 运维诊断与知识问答 Agent（从 0 到 1）
> 定位：**企业内部流程 Agent + 评测基础设施**——面向 15 微服务交易系统，把"跨 5 套系统人工排查"变成"对话式分钟级取证"，危险变更全程 HITL 审批与可校验审计。
> 关键词：Agent 工具治理、评测体系、成本与权限、可靠性工程

- **故障定位效率**：设计"日志/指标/trace/死信/代码"四域 **16 个全自研工具**的证据链 Agent；**10 个真实故障案例实测 10/10 证据完整，Agent 均值 1.63 分钟**，人工口径保守重构 20.6 分钟 → **降幅 92.1%**（口径：Agent 墙钟实测 + 人工重构下界）。
- **评测体系与质量门禁**：建立三层评测——检索级（**hit@1=100%**，30 条）、答案级（**50/50 全过、引用有效性 100%**，含幻觉引用硬拦截）、Agent 级（**工具选择 12/12**；轨迹评测支持部分分，4 例×3 次稳定性 **0.917**）；门禁脚本一键跑单测 + 审计一致性 + 哈希链（可选评测），接入 CI。
- **工具工程（LLM 视角）**：把裸 DSL/PromQL 收回服务端，暴露 16 个扁平业务参数工具——同题实测 **P95 排查 98s 答偏 → 50s 答对**；沉淀"工具参数面向 LLM 设计"审查门禁；实测发现并修复"工具注册成功但从不执行"（框架权限默认 ASK 挂起）类隐蔽缺陷。
- **可靠性与工程判断**：框架不支持工具级热替换 → 决策**去 MCP 化**（工具全自研，kill 两个 MCP 进程仍可完成 ES/Prom 诊断，19s/39s）；审批执行崩溃**自动补执行 + 卡死回收**；Redis 状态丢失时从消息表 + 会话摘要**重建上下文**（删状态追问仍能答出关键事实）。
- **成本与权限边界**：按用户 token 预算三段治理（真实 usage 计量 → 软限切轻量模型 → 硬限 429），单次诊断 **18,292/1,433 tokens ≈¥0.012–0.048**，较全量上下文直塞输入降幅约 **74%**（估算）；并发护栏（单用户 2/全局 8）；RBAC 消费平台 JWT 角色，管理端点收敛 ADMIN；审计**哈希链防篡改**（篡改可检出）；请求幂等（重复提交 0s 返回、并发 409）；7 条 Prometheus 告警覆盖可用性/熔断/预算/工具 schema。
- **安全验证**：红队 **8 项全拦截**（未授权/注入/密钥诱导/越权审批/危险工具/洪水/方法混淆/直调）；敏感数据出网默认脱敏；"未审批高危执行 0" 审计 SQL 可验。
- **边界（主动写）**：单机内测环境，未承接真实用户流量；多租户隔离/DLP/LLM-judge 人工抽检为下一步。
