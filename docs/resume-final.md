## 一、个人定位

高并发分布式后端 + AI 应用工程（Java / Spring Cloud / RocketMQ / Redis / ES / AgentScope）。
两个可深挖项目：**15 微服务交易系统的一致性治理与稳定性优化**；**从 0 到 1 的 AIOps 诊断与知识问答 Agent**。

## 二、项目一：交易系统优化（15 微服务 / 8 类中间件）

> 一句话：面向 15 个 Spring Cloud 微服务与 8 类中间件的电商交易系统，主导**一致性、消息治理、容灾复盘**方向的深度优化，并沉淀可复现的验证体系。

**关键结果（每条均可追证）**
1. **分布式一致性体系落地**：库存链路自研 TCC + Fence（空回滚/悬挂/幂等三异常，11 场景实测通过）；订单链路"事务消息 + 本地消息表 + 75s 回查"，重复投递由 `markSuccessByTransactionId` + 消费端幂等消除；8 个对账/修复 Job（库存/券/购物车/未读/关注/本地消息/超时关单/订单映射）构成最终一致兜底。
2. **消息治理与 DLQ 清零**：定位并修复 3 组历史 DLQ（购物车事件流水无 SKU 动作落库失败、搜索索引消费者韧性缺陷等），全平台 `%DLQ%*` 积压清零；消费者补齐**失败分类**（可重试 vs 确定性失败）、**版本幂等**（ExternalGte/冲突跳过）；死信监控从硬编码 22 组修正为对齐实际 **26 个消费组**（补齐 8 个盲区组），修复"指标恒为 0"的算法缺陷。
3. **性能与容量基线**：压测建立服务级基线（商品 1020 / 笔记 1096 / 首页 764 / 推荐 761 / 搜索 683 RPS；搜索 P50 29ms / P99 96ms）；网关分级限流（内容/商品 500、首页/推荐 300 QPS）；**6 秒慢下游注入下首页按 200 QPS / 2s 超时受控降级**。
4. **容灾与自愈**：Redis Sentinel failover 演练 2.3s 切换、数据无损；Elasticsearch 停机演练受控降级（检索类工具报错不拖垮服务）；MCP 子进程 kill 演练驱动"30s 探测 + 两连击 + 限流 fail-fast + 守护进程拉起"的进程级自愈（≈90s 恢复）。
5. **可观测与工程治理**：ELK（Filebeat/Logstash）+ SkyWalking + Prometheus/Alertmanager/Canal 全链路；traceId 跨 HTTP/MQ/长连接透传；117 项测试矩阵 + 21 个运行态问题修复闭环；Maven Enforcer 依赖收敛（重复类/版本漂移/okhttp 双实现清零）。

**边界（主动承认）**：对账与在线写无屏障（收敛历史差异，不保证实时一致）；订单分片 4×4 无 rehash 方案（扩容是已知短板，正解为双写迁移/基因分片）；TCC 与普通分桶库存是两本账，靠对账隔离。

## 三、项目二：xhs-ai — AIOps 诊断与知识问答 Agent（从 0 到 1）

> 一句话：以自然语言为入口，编排 4 域 27 个工具（DLQ/指标/日志/知识/代码，白名单），输出**可回链的定位结论**；高危变更走 HITL 审批与全量审计。

**关键结果**
1. **故障定位效率**：10 个真实故障案例实测 **10/10 证据完整**，Agent 均值 **1.63 分钟**；人工口径保守重构 20.6 分钟 → **降幅 92.1%**（原始数据入库）。
2. **可度量质量体系**：知识卡 55 张；KB 检索 30 条 **hit@1=100%**；答案级评测 **50/50**、引用有效性 **100%**（幻觉路径被硬校验拦截）；红队 **8 项全拦截**；"0 未审批执行"审计 SQL 可验。
3. **可靠性工程**：模型网关（重试/熔断/降级/指标）；审批超时 fail-closed + 跨实例决策事件 + 消息队列级消费位点核验（重投效果可证）；工具预算护栏（软 32/硬 40 + 指标）；MCP 进程级自愈。
4. **成本精细化**：单次诊断 18,292 input / 1,433 output tokens（≈¥0.012–0.048，费率待官方确认），较全量上下文直塞输入降幅 ~74%（估算，N=10 诊断 + 100 轻量采样）。
5. **评测驱动的选型**：以 BM25+结构化卡为基线，向量方案按止损规则不启动（基线已 100%）；代码导航 v1（文件:行号）；每次评审（RV06-RV19）留档。

**边界（主动承认）**：MCP 工具级热替换受框架限制（运行时重挂后工具不重绑，故用进程级自愈）；单机测试环境，不宣称生产容量。
