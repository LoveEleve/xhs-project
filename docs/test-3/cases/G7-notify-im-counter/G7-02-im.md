## 代码实证（2026-08-14，G7 梳理全量核实）

### 端点与安全（gateway:19000 → im:19014）
| 端点 | 鉴权 | 说明（代码实证） |
|---|---|---|
| POST /api/im/ws/ticket | **JWT（免 HMAC）**——**执行实证：hmac-white-list `/api/im/ws/**` 覆盖 ws/ticket**（初版文档误判需 HMAC）| 签发 WS ticket：JWT（type=ws_ticket，5 分钟，jwt.secret）；无 token → 401 |
| GET /api/im/conversations | **JWT（免 HMAC）** | 会话列表分页；size≤50；orderByDesc(updatedAt) |
| GET /api/im/messages/{peerId} | JWT + HMAC | 历史消息分页；size≤100；orderByDesc(seqNo)；无会话关系 → 空 |
| POST /api/im/read/{peerId} | JWT + HMAC | @RateLimit 20/60s；DB 未读清零 + Redis Hash 归零 |
| GET /api/im/unread-count | **JWT（免 HMAC）** | 总未读（Redis Hash sum；无缓存时 DB 兜底）|
| GET /api/im/online-count | **JWT 白名单 + X-Admin-Call** | localOnline + serverId |
| WS /api/im/ws?ticket= | **JWT 白名单**（应用层握手校验）| WebSocket（`im.websocket.path=/api/im/ws`）|

### WS 握手（ImHandshakeInterceptor，代码实证）
- URL 参数 ticket → JwtUtil.parseToken（jwt.secret）→ **type 必须 = "ws_ticket"**（防 access token 冒充）→ userId 放入 session attributes
- ticket 缺失/无效/类型错误 → 拒绝握手（403）

### 连接生命周期（ImWebSocketHandler，代码实证）
- afterConnectionEstablished：连接数上限 50000；**同用户踢旧**（旧连接 CloseStatus 4001"新设备登录"）；registerRoute（`myxhs:im:route:{uid}`=serverId + `myxhs:im:online:{uid}`=1，**TTL=3×心跳=90s**）；pushOfflineMessages
- handleTextMessage：消息类型 CHAT/ACK/READ/TYPING/PING/LOGOUT；未知类型仅日志
- afterConnectionClosed：sessions.remove(uid, session)（防误删新连接）+ unregisterRoute（Lua 原子：serverId 匹配才删）
- PING → PONG + renewRoute（续期 90s）

### 聊天链路（ChatService.handleChat，代码实证）
1. 校验：receiverId 非空且 ≠ sender；content 非空；超 2000 截断 → NACK
2. msgId=IdWorker、conversationId=resolveConversationId（**P0-B：复用关系表全局唯一 ID，非 min*31+max**）、seqNo=INCR `myxhs:im:seq:{conversationId}`
3. **写扩散双写事务**（MessagePersistService @Transactional）：t_chat_message INSERT（conversationId 分片）+ t_chat_user_relation 双向 upsert（sender unread=0 / receiver unread=1）；失败 → NACK"发送失败，请重试"
4. **路由投递**：同实例直推 → 失败存离线；跨实例 Redis Pub/Sub `myxhs:im:route:{serverId}`；不在线 → storeOfflineMessage（ZADD `myxhs:im:offline:{uid}` score=时间，**1000 上限裁剪 + 7 天 TTL**，Lua 原子）
5. 未读：HINCRBY `myxhs:im:unread:{receiverId}` senderId +1
6. ACK 给发送者

### 离线消息（代码实证）
- 发送时接收者不在线 → 存 msgId 到 ZSet；**上线时 pushOfflineMessages**：ZSet range → DB selectBatchIds → **按 seqNo 升序** → 推送 `OFFLINE` 事件（msgs[]+total）→ **客户端逐条 ACK（ZREM）**
- 连接中但路由过期（90s 无心跳）→ 消息存离线

### 已读（handleRead / markAllRead，代码实证）
- WS READ → DB unread_count=0 + Redis Hash 归零 + **READ_NOTIFY 推送对方**（跨实例 msgType=99 特殊处理）
- REST read/{peerId} → DB + Redis 归零（不推送）

### 会话/历史（代码实证）
- 会话列表：t_chat_user_relation（is_deleted=0，orderByDesc updatedAt）→ ConversationVO{peerId,lastContent,lastMsgType,unreadCount,updatedAt}
- 历史：getExistingConversationId（双向查）→ 无关系返回空页；t_chat_message orderByDesc(seqNo)

### 错误码/协议
- REST：200 / 403 / 40002（无——REST 参数宽松）
- WS 帧：ACK（msgId）/NACK（reason）/CHAT/OFFLINE/READ_NOTIFY/TYPING/PONG/LOGOUT

## 用例清单

### G7-02-01 WS ticket + 握手（两步鉴权）
- **入口**：`POST /api/im/ws/ticket`（JWT+HMAC）→ data.ticket 非空
- **JWT 解码**：ticket claims type=**ws_ticket**、sub=uid、**exp=now+300s**（5 分钟实证）
- **握手**：ws://localhost:19000/api/im/ws?ticket={ticket} 建连 → 成功（HTTP 101）
- **负面**：无 ticket → 拒绝；**access token 冒充**（Authorization 的 accessToken 当 ticket）→ 拒绝（type≠ws_ticket）；过期 ticket（自签 type=ws_ticket exp 过去）→ 拒绝
- **🔍 人工观察**：Kibana im 日志"[IM] 连接建立"

### G7-02-02 连接 + 在线路由（矩阵 #27）
- **前置**：g7a_ WS 连接保持
- **L2**：`myxhs:im:online:{g7a.uid}`=1（TTL≈90）、`myxhs:im:route:{g7a.uid}`=serverId（TTL≈90）
- **在线计数**：`GET /api/im/online-count`（JWT + X-Admin-Call）→ localOnline≥1 + serverId 匹配 Redis 值
- **断开**：关闭 WS → im:online/im:route **立即删除**（unregisterRoute Lua 实证）
- **90s 过期**：不关闭但停心跳（不 PING）→ 等 90s → key 自然过期（在线消失）——**标注：90s 等待可选（或 TTL 操纵 DEL 验证同效）**

### G7-02-03 CHAT 消息全链路（核心，同实例直推）
- **前置**：g7a_ 与 g7b_ 都建立 WS 连接
- **g7a_ 发**：`{"type":"CHAT","to":{g7b},"content":"g7im 你好","msgType":0}`
- **L1 断言**：
  ```
  # ① g7a_ 收到 ACK（msgId/timestamp）
  # ② g7b_ 收到 CHAT（ver=1/msgId/seqNo/from=g7a/content/msgType/timestamp）
  ```
- **L2**（等 1-3s 主从）：
  ```
  # ① t_chat_message：sender_id=g7a/receiver_id=g7b/conversation_id 一致/seq_no=1（首消息）/content
  # ② t_chat_user_relation：g7a→g7b（unread_count=0）+ g7b→g7a（unread_count=1）双写
  # ③ seqNo：myxhs:im:seq:{conversationId}=1（INCR 实证）
  # ④ 未读：HGET myxhs:im:unread:{g7b.uid} {g7a.uid}=1
  ```
- **负面**：发给自己（to=sender）→ NACK"无效的接收者"；空内容 → NACK"消息内容不能为空"；>2000 字 → 截断 2000（发送成功 content 长度 2000）

### G7-02-04 会话 seqNo 递增与顺序
- g7a_ 连发 3 条 → seqNo=2/3/4 严格递增（Redis INCR + t_chat_message.seq_no）
- **历史查询**：`GET /api/im/messages/{peerId}?page=1&size=50` → records 按 **seqNo 降序**（最新在前）；total 递增

### G7-02-05 会话列表 + 未读
- **入口**：`GET /api/im/conversations`（JWT 免 HMAC）→ records 含 peerId=g7a、lastContent、unreadCount=1（g7b 视角）
- **未读**：`GET /api/im/unread-count`（JWT 免 HMAC）→ total=1（Redis Hash sum）
- **无会话用户** → records 空、total=0

### G7-02-06 已读回执（WS READ）
- g7b_ 发 `{"type":"READ","peerId":{g7a}}`
- **L1**：g7a_ 收到 `READ_NOTIFY`（peerId=g7b、msgId）
- **L2**：t_chat_user_relation（g7b→g7a）unread_count=0；`HGET myxhs:im:unread:{g7b.uid} {g7a.uid}`=0；`/api/im/unread-count` → 0
- **REST 对照**：`POST /api/im/read/{peerId}`（JWT+HMAC）→ 同效果（不推送 READ_NOTIFY——代码实证）

### G7-02-07 离线消息（核心）
- **前置**：g7b_ 断开 WS（不在线）
- g7a_ 发 2 条 → 无直推对象 → **storeOfflineMessage**
- **L2**：`myxhs:im:offline:{g7b.uid}` ZSet 含 2 个 msgId（score=时间；**TTL≈7 天**）
- g7b_ 重新连接 → 收到 `OFFLINE` 事件（msgs 2 条**按 seqNo 升序** + total=2）
- g7b_ 逐条发 `{"type":"ACK","msgId":{id}}` → ZSet 成员删除（ZREM 实证）
- **上限裁剪**：SADD 1001+ 个 msgId（③ 操纵）→ 保留最新 1000（Lua 裁剪）

### G7-02-08 心跳（PING/PONG + 90s TTL，矩阵 #27）
- g7a_ 发 `{"type":"PING"}` → 收 `PONG`
- **L2**：im:route/im:online TTL 刷新（≈90 复位）
- **30s 心跳间隔语义**：客户端 30s PING 一次可保活（im.websocket.heartbeat-interval=30000 配置实证）；**90s 不 PING → key 过期 → 新消息存离线**（TTL 操纵：DEL 后发消息验证走离线分支——可选）

### G7-02-09 踢下线（同用户新连接）
- g7a_ 建立第二个 WS 连接 → **旧连接收到 CloseStatus 4001"新设备登录，当前连接已断开"**
- **L2**：sessions 仅 1 个新连接；im:online/route 指向新连接（registerRoute 覆盖）；旧连接关闭回调 **不误删新路由**（remove(uid, oldSession) + unregister Lua 实证）

### G7-02-10 IM 鉴权矩阵（安全）
- ① `messages/{peerId}`、`read/{peerId}` 无 token → **401**；带 token 无 HMAC → **403**；**ws/ticket 带 token 无 HMAC → 200（ws/** 白名单覆盖，执行实证）**；ws/ticket 无 token → 401
- ② `conversations`、`unread-count` 带 token 无 HMAC → **200**（免 HMAC）
- ③ `online-count` 无 X-Admin-Call → 403
- ④ **WS 端点需经 gateway**：直连 im:19014/api/im/ws?ticket=（绕过 gateway）→ 应用层校验仍生效（ticket 机制独立于 gateway 鉴权——**标注：直连 19014 也可建连（端口信任模型 #60 已修 gateway 注入，但 WS 用 ticket 应用层校验）**）

### G7-02-11 IM 限流（矩阵 #26）
- `POST /api/im/read/{peerId}` 连打 21 次 → 第 21 次 **40202**（20/60s）；执行前 DEL `myxhs:im:read:ImController:markAllRead:{uid}`

### G7-02-12 消息协议负面（WS）
- 非法 JSON → 日志忽略（无 NACK——代码实证仅 warn）；未知 type（如 "FOO"）→ 日志忽略；`{"type":"CHAT","to":null}` → NACK"无效的接收者"
