# SkyWalking Agent 开销实测（2026-09-18）

> 目的：量化 APM agent 的性能开销，明确性能基线的口径（有/无 agent），避免"简历数字不可复现"。
> 方法：同一服务（product 19006）、同一压测命令，agent 开/关各两轮交替取样。

## 一、方法

- 工具：`wrk -t4 -c32 -d30s --latency`（与历史压测一致的 4 线程/32 连接）
- 目标：`GET http://localhost:19006/api/product/spu/1`（免鉴权商品详情，走缓存）
- 开关：`SW_AGENT_DISABLED=1` 发布 → 关；正常发布 → 开（每轮重启后 10s 预热再正式测）
- 顺序：ON₁ → OFF₁ → OFF₂ → ON₂（交替以抵消环境漂移）

## 二、结果

| 轮次 | RPS | P50 | P99 |
|---|---|---|---|
| ON₁ | 7,209 | 2.89ms | 53.85ms |
| OFF₁ | 7,774 | 2.37ms | 60.68ms |
| OFF₂ | 7,952 | 2.28ms | 59.97ms |
| ON₂ | 7,668 | 2.58ms | 55.57ms |
| **OFF 均值** | **7,863** | 2.33ms | 60.3ms |
| **ON 均值** | **7,439** | 2.74ms | 54.7ms |

- **吞吐开销 ≈ 5.4%**（(7863−7439)/7863）；P50 +0.41ms（+17.6%）
- P99 在 agent ON 时反而略低（53.9/55.6 vs 60.0/60.7）——属测量噪声，不作为结论
- 环境为共享单机 + 服务进程其他负载轻微波动，单轮方差存在（故取两轮均值）

## 三、口径结论（重要）

1. **历史基线 4,871 RPS 为"无 agent"口径**（且为另一套方法与缓存状态，不可与本次 7,863 直接比较）；
2. 当前生产（含 agent）product 实测 **≈7,400 RPS**；同类比的"无 agent 参考值"≈7,900 RPS；
3. 若面试引用性能数字：说明"无本地缓存、无 APM agent 的基线 4,871"或"当日实测口径 7.4k/7.9k（agent 开/关）"二选一，**不可混用**；
4. 采样默认 1/3s 已含在上述开销内；全采样（`SW_AGENT_SAMPLE=-1`）会更大，压测时应 `SW_AGENT_DISABLED=1`。
