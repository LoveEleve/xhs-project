# 遗漏盘点（2026-09-20）：备份/版本门缺口/超时/WS 网关

> 用户问"还有什么遗漏"——系统扫了一遍，**最大盲区在运维/DR 面**（不是业务代码）。本轮修复 4 项，登记 6 项待决策。

## 一、本轮修复（已发布/已验证）

### ① MySQL 备份：脚本长期静默产出"空备份"（最严重）
- 现象：`/opt/backups/mysql/*.sql.gz` 全部 **20 字节**；无任何 cron 调度。
- 根因：脚本是**旧云环境模板**——写死 `host=21.91.124.110`、端口 `13306-13309`（本环境均为无效端口），且 `mysqldump ... 2>/dev/null` **吞掉错误**、无任何校验；宿主机也没有 mysqldump（证实旧脚本不可能工作）。
- 修复：重写 `deploy/scripts/mysql-backup.sh`——走 `docker exec my-xhs-mysql mysqldump`（真实主库 3306）、`pipefail`、**成功后校验 size≥100KB + gunzip -t**，失败即非 0 退出并清理残缺文件。
- 验证：实跑产出 **3.0MB** 实体备份（含 `CREATE DATABASE`/`Dumping data`）；新增 cron `/etc/cron.d/myxhs-backup`（每日 3:30，保留 7 天）。

### ② counter 收藏计数仍缺版本门（与已修的点赞同类缺陷）
- 修复：`CounterEventConsumer.handleFavoriteEvent` 增加 `actionTime` 版本门（独立 key）。
- 验证（MQ 注入 FAVORITE/UNFAVORITE 带 Tag）：FAVORITE(新)→收藏=1；**UNFAVORITE(旧) 被拒**（日志"跳过旧收藏事件(版本门)"、收藏保持 1）；UNFAVORITE(新)→0。

### ③ search 缺 Feign 超时（60s 挂起风险）
- 修复：补 `connect-timeout/read-timeout: 3000`；回归 **test-14 20/20**。

### ④ IM WebSocket 经网关路径（白名单/代理）实测
- `ws://127.0.0.1:19000/api/im/ws?ticket=...` **连接成功，PING→PONG** ✓（白名单含 `/api/im/ws`，网关 WS 代理正常）。
