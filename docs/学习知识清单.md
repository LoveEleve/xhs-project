# 学习知识清单（xhs 平台 + xhs-ai，条目式）

- [ ] Java 17：record / sealed class / switch 表达式 / 文本块 / 虚拟线程

## 二、Spring 生态

- [ ] Spring Cloud LoadBalancer：服务列表、zone 优先路由

- [ ] 选型对比：Dubbo vs Feign、Seata vs 自研 TCC、RedLock vs 单点锁
