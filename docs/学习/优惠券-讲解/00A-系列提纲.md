## 00 应然模型与学习路线（总纲）

- 一张 20 元券的一生（领→用→退→过期）；三个库存口径（Redis stock / MySQL remain / claimed）。
- 三个问题：不超发 / 不重复 / 必达；三个取舍：双库存、下单即核销、RV30 退券不回补。
- 10 篇路线图 + 30 秒面试开场。

## 01 券的业务模型（业务）

- **目标问题**：一张券由哪些规则定义？真实系统该有什么、本项目简化了什么？
- **核心结论**：类型（满减/折扣/无门槛）、门槛、有效期、发放量、限领是**最小规则集**；
  叠加/互斥、定向发券、兑换码、锁定态核销是**应然缺口**（本项目单券、下单即核销）。
- **小节**：
  1. 例子：淘宝一笔 300 元订单（店铺券 + 跨店满减 + 红包；锁定→支付核销→释放）
  2. 生产券体系：多券/叠加互斥/发放/分摊/有效期/风控
  3. 本项目实然：3 种券、单券、下单即核销、order 行级分摊（discount_share）
  4. 对照表：差异是取舍；分摊这一项本项目接近生产
- **证据**：`CouponTemplate`、`CreateTemplateRequest`、`03-优惠券.md` §2。
- **追问链**：为什么不做叠加→下单即核销的风险→锁定态怎么实现（设计）。

## 02 领券：库存与限领（业务+分布式）

- **目标问题**：高并发领券怎么不超发？限领怎么保证？Redis/MySQL 两个库存怎么配合？
- **核心结论**：Lua 一步完成"库存检查 + 限领 + DECR + INCR"；`{templateId}` 同 slot；
  `stock` 是同步闸门，`remain_count` 是异步落账；`-3` 从 DB 实时自愈重试一次。
- **小节**：
  1. 例子：1000 张券、1 万人抢；Lua 5 步与 4 种返回（1/-1/-2/-3）
  2. 为什么必须 Lua（读-判-写原子；Cluster 同 slot）
  3. 双库存：Redis 闸门 vs MySQL 落账（对账见 04）
  4. 限领计数 `claimed:{userId}` 的语义（含已用/已过期）
- **证据**：`CouponService.claimCoupon`、`claim_coupon.lua`、`getTemplateWithCache`。
- **追问链**：Lua 为什么不能拆→库存 key 丢了怎么办→Redis 扣了 DB 没落（→05）。

## 03 用券：校验与折扣（业务）

- **目标问题**：下单时券怎么校验？折扣怎么算？怎么防重复核销/金额不一致？
- **核心结论**：校验链（金额→有效期→状态）；折扣 `min(orderAmount)` 防 0 元购；
  `markUsed` 乐观锁（`status=0` + `used_order_id`）；**下单即核销**（无锁定态）。
- **小节**：
  1. 例子：120 元订单用满 100 减 20，试算 vs 核销
  2. 校验责任链（为什么拆 validator；`@Order`）
  3. 折扣计算（满减/折扣/无门槛）与 0 元购
  4. 乐观锁核销 + 订单金额一致性（order 侧校验）
- **证据**：`getCouponDiscount/useCoupon`、`validator/*`、`UserCouponMapper.markUsed`。
- **追问链**：重复提交→核销后支付失败（→04）→下单即核销 vs 锁定态（设计）。

## 04 退券、过期与对账（业务）

- **目标问题**：退券为什么不回补库存？过期怎么标？对账修什么、以谁为准？
- **核心结论**：RV30 只恢复用户券状态（`status=1 AND used_order_id=orderId → 0`），
  不回补 stock/remain、不减 claimed（防超发敞口 + 防绕限领）；过期 Job 分批 0→2；
  对账三件事：stock（Redis 为准）、claimed（DB 已发券为准）、卡住 outbox 告警。
- **小节**：
  1. 例子：退券后 remain 为什么不变？再领为什么被限？
  2. RV30 的两个理由（超发敞口/绕限领）
  3. 过期：预检 Job + 延时消息 + 兜底 Job（23h 分段见 06）
  4. 对账三件事与"以谁为准"
- **证据**：`returnCoupon`、`CouponExpireJob/PrecheckJob`、`CouponReconcileJob`。
- **追问链**：退券后库存对不上→过期券算不算已发→对账发现 remain 多了修谁。

## 05 超发洞与 Design B（分布式）

- **目标问题**：Redis 扣了名额、DB 落账失败/消息丢了，怎么办？回滚 Redis 为什么反而超发？
- **核心结论**："回滚掩码"：发送失败回滚 Redis，但消息可能已存 → 回滚 + 补投 = 超发；
  Design B：名额锁定即成功 + Outbox（先写行再发）+ 至少一次 + `uk_claim_no` 幂等；
  唯一回滚路径 = Outbox 双次写入失败。
- **小节**：
  1. 例子：claim 成功 → MQ 发送超时 → 旧实现回滚 → 消息补投 → 用户两张券
  2. Design B 发送链（outbox 写入/发送/失败语义/双次写入）
  3. 消费端幂等：**完成态标记**（`isProcessed/markProcessed`）+ `uk_claim_no` + `decrementRemainCount`
  4. 为什么"至少一次"比"回滚"安全（漏损 vs 超发方向）
- **证据**：`sendClaimEventSync`、`CouponClaimConsumer`、`CouponOutboxSenderJob`、C-007。
- **追问链**：outbox 写失败→重复投递怎么幂等→DLQ 重放会不会超发（G35，→09）。

## 06 规模化：分片 / 延时 / 推送（分布式）

- **目标问题**：怎么把券域扩到 32 分片、亿级记录？延时过期和推送引擎怎么做？
- **核心结论**：`t_user_coupon` 按 `user_id` 2 库 × 16 表；模板/Outbox/推送记录单表；
  按 id 读写补 `user_id` 避免广播；**跨库事务拆分**（插券为准，remain 派生 + 对账）；
  RocketMQ 24h 窗口下 **23h 分段延时**；推送引擎 = 分桶 + 800KB 批分割 + 线程池/Semaphore。
- **小节**：
  1. 分片设计（库/表算法、`!SINGLE`、SQL 迁移）
  2. 跨库事务：为什么不能本地事务；派生账本 + 对账
  3. 延时过期：预检 Job + 23h 分段 + 消费续排 + 兜底 Job
  4. 推送引擎：分桶（1000/片）、批分割、共享线程池、通知投递、幂等表
- **证据**：C-017 全部产出（`sharding-config.yaml`、`CouponExpireDelayProducer`、`CouponExpiryPushJob`）。
- **追问链**：为什么模板不分片→分片后跨分片查询→24h 延时上限→推送怎么限流。

## 07 域边界与契约（微服务）

- **目标问题**：coupon 和 order/payment/inventory/notification 的边界怎么划？失败怎么表达？
- **核心结论**：coupon 拥有券模板/用户券/名额；order 是编排者（试算/核销/退券）；
  payment 不碰券；notification 只负责投递；coupon 不写对方表，只提供内部契约。
- **小节**：
  1. 例子：下单用券 → 支付/取消 → 退券，四个域各自做什么
  2. 双向契约（`discount/use/return`、`NOTIFICATION_TOPIC`、`ORDER_TERMINATION_TOPIC`）
  3. 失败语义（业务拒绝 vs 503 vs 超时；重复/幂等）
  4. 内部鉴权（`X-Internal-Call`）与越权
- **证据**：`CouponController`、`OrderFeignClient`、`OrderTerminationConsumer`、`CouponPushSender`。
- **追问链**：为什么 payment 不核销券→退款谁退券→通知失败谁兜底。

## 08 性能与热点（性能）

- **目标问题**：券域的性能瓶颈在哪？热点怎么扛？分片/推送怎么限流？
- **核心结论**：领券热点在 Redis（Lua 单 slot）；DB 是异步落账；查询走 user_id 单分片；
  推送用"分桶 + 批分割 + Semaphore"背压；模板缓存防穿透；热 key 用 `{templateId}` 同 slot。
- **小节**：
  1. 领券链路：Lua 原子 vs 多次往返；同 slot 的意义
  2. 双库存与对账的吞吐取舍（Redis 快、MySQL 慢半拍）
  3. 查询：user_id 路由、模板批量查询（消除 N+1）、分页上限
  4. 推送：1000/片、800KB/批、Semaphore 限流、失败重试
- **证据**：`claim_coupon.lua`、`getAvailableCoupons`、`CouponExpiryPushJob`、C-017。
- **追问链**：热 key 怎么发现→Redis 挂了怎么办→分片后跨分片查询多少。
