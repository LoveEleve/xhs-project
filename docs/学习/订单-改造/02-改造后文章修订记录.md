1. **先读 09（拆单）→ 10（分摊）→ 08（售后）**：三篇是改造核心（父/子/行 + 行级售后 + 行级金额），对照新代码学习收益最大；

4. 每篇学习时以本记录"改造后"列为口径，遇到与正文冲突处以新代码为准。
