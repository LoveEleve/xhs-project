## 总变化速览（C-008 三大项）

1. **键模型收敛**：去分桶（单库存键）+ 预扣记录 per-(sku,order) String 单键 + 每脚本单 slot（Cluster 兼容）；
2. **幂等语义**：L1 完成态标记 / L2 事务内幂等表 / 退款回补同槽原子脚本（"前置标记"全部废除）；
3. **兜底补齐**：DLQ 重放 ×3 组、对账 CAS、items 契约（confirm/release 携带 SKU 列表）、F12 确认标记强化。

## 面试口径更新（分桶相关）

> "分桶机制我们完整评估过：单实例零收益（Redis 单线程）、同 slot 下集群也零收益、total 热 key 把理论收益也抵消——正确形态需要分片+桶粒度 tag+放弃跨 key 原子（对账兜底）。**评估后主动移除**，键模型收敛为单键 + 每脚本单 slot（集群正确）。"——比"有个名不副实的分桶"高一个段位。
