# 开源项目 · Poly 系列（5 个独立项目 · github.com/LoveEleve/poly-project）

异地多活架构项目（PolyZone）
● 区域定位：构建统一的可用区（Availability Zone）定位抽象，支持 AWS EC2 / ECS 容器元数据与本地属性四种定位方式，任意部署环境自动识别所在区域，定位器可扩展
● 同区域优先：服务调用与网关流量优先选择同区域节点；内置三重保护（实例就绪率、同区域最小可用数、禁用区域剔除），条件不满足自动退回全量列表，避免区域偏好导致无节点可用；偏好策略可动态开关
● 故障转移：配置中心修改区域配置后，应用与网关自动切换到健康区域，事件驱动、无需重启
● 故障恢复：回滚配置即恢复原区域策略，记住首次自动识别的原始区域，支持反复故障转移与恢复

动态数据库 Sharding 项目（PolyData）
● 模块化设计：MyBatis、MyBatis-Plus、事务、动态数据源、多活能力、分库分表六大模块，统一四个扩展点即插即用
● 动态数据源：运行时热更新数据源（配置深克隆 → 独立子上下文隔离 → 原子切换 → 旧资源延迟释放），支撑同区域优先、故障转移与故障恢复的事件驱动重建，全程不停机
● 多框架并存：多套 JDBC 框架（MyBatis 与 MyBatis-Plus）在同一应用内隔离并存，各自独立连接池与会话工厂，互不干扰
● 支持 Apache ShardingSphere 5.x：YAML 配置直接生成分片数据源，不依赖官方 starter，分库分表路由经真实数据验证

Redis 异地多活架构项目（PolyCache）
● 多机房同步：基于 Redisson 无侵入拦截写命令（业务代码零改造），经 Kafka 按 key 有序投递，异地机房精确回放；至少一次投递保证不丢，来源过滤与独立回放链路双防护避免复制循环，支持 Redis 集群模式，经真实双机房环境演练验证
● 零侵入接入：以 Spring Boot Starter 接入，Java 应用无需调整配置和代码；拦截层与业务 Redis 指令完全隔离，捕获故障不影响业务请求执行；提供可插拔扩展点支持自定义过滤、脱敏与审计
● 故障转移：运行时动态切换 Redis 目标节点（线程级作用域切换、自动恢复不留线程污染），支持目标节点热替换，配置变更无需重启；脚本与批量写入语义完整兼容

配置中心统一抽象项目（PolyConfig）
● 声明式配置：注解即接入 Nacos 配置中心，支持自动刷新、多配置源优先级定位与 YAML / properties 双格式
● 统一变更事件：以属性粒度输出变更前后值与变更来源，兼容 Spring Cloud 原生刷新机制，下游组件一套监听即可适配多个配置中心
● 多后端扩展：模板化接入层，新增配置中心（Apollo / etcd）仅需实现两个方法

端点级网关路由项目（PolyGateway）
● 端点自动发现：业务服务启动时自动采集对外 HTTP 接口（路径 / 方法 / 参数 / 请求头 / Content-Type / Accept）并写入注册中心元数据，服务零接入成本，自动排除管理类端点，跨实例采集结果一致
● 端点级路由：网关根据元数据自动生成接口级精确路由，复用 Spring Cloud Gateway 官方谓词与响应式负载均衡，网关线程零阻塞、路由可视化；支持按服务 / 路径 / 方法隐藏内部接口（不生成路由，不可达即 404），并按规则为接口挂载限流与重试
● 实时生效：注册中心心跳即刷新路由，服务发布新接口后无需重启网关即可访问
● 依赖精简：网关依赖可选化引入，仅提供采集端的服务无需引入网关栈，与服务解耦
