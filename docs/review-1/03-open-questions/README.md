# 03-open-questions

## 目标

收纳所有当前不能仅靠代码与配置直接定性的事项，避免把假设写进 findings。

## 这里放什么

1. 业务语义待确认
2. 团队边界待确认
3. 历史兼容约束待确认
4. 运行态与代码不一致但原因未明的问题
5. 第三方系统行为假设

## 单条问题模板

1. 问题描述
2. 为什么目前无法定论
3. 需要谁确认
4. 若答案为 A 的影响
5. 若答案为 B 的影响
6. 后续验证方式

## 典型问题示例

- 某接口 200 是设计如此还是越权放过
- 某补偿行为是最终一致性策略还是状态机漏洞
- 某 AI 能力是否允许经公网入口直接触发
- 某脚本的健康检查成功是否只是端口假阳性
