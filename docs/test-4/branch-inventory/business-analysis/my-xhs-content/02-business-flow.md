# my-xhs-content 业务链路与源码流转

## 1. 笔记发布

```text
POST /api/note/publish
  -> DTO 校验
  -> DFA 敏感词检测
  -> 写 t_note(status=PUBLISHED,auditStatus=APPROVED)
  -> 写 t_note_event
  -> 写 t_local_message(status=待发送)
  -> 事务提交后发送 FEED_TOPIC
  -> Feed 消费者写 Redis inbox
  -> FeedMessageRetryJob 扫描补偿
```

当前实现把 DFA 通过视为审核通过，跳过人工审核队列。虽然枚举中存在 `AUDITING`、`REJECTED` 等状态，但发布路径始终直接进入已发布/已通过，审核字段不是完整状态机。

本地消息体存在时序缺陷：事件序列化和写入消息体后才设置 `localMsgId`，所以首次即时发送与数据库 payload 可能缺少本地消息 ID。补偿任务再补写内存对象不能修复已经持久化/发送出去的第一份消息。

## 2. 草稿保存与发布

草稿保存进入 `DRAFT/PENDING`，不进入 Feed。发布草稿重新做 DFA，再条件更新为已发布/已通过，然后写事件、本地消息并在事务提交后发 Feed。

发布草稿存在两个一致性问题：
- 查询与更新之间没有锁或状态条件，重复发布可重复写事件和消息
- `update` 返回值未检查，实际未更新也可能继续返回成功

## 3. 已发布笔记更新

```text
校验作者和状态
  -> 已发布内容重新 DFA
  -> 局部更新 t_note
  -> 事务提交后删除详情缓存
```

局部更新避免了全量覆盖，但没有版本号/更新时间条件，两个并发更新仍是最后写入覆盖。更重要的是，更新没有重新进入审核，也没有向 Feed、搜索索引或推荐发送更新事件，详情、Feed、ES 可能出现不同版本。

## 4. 详情与列表

详情采用 Cache Aside：已发布笔记读取 Redis，未命中回源 MySQL，空值短 TTL，成功结果带随机 TTL。读取详情会发送浏览事件，批量详情不发送浏览事件。

批量详情只是批量 HTTP 外壳，内部仍逐个读取缓存/数据库；单个读取异常被跳过，调用方无法区分“没有该笔记”和“某个下游失败”。用户笔记列表使用 OFFSET 分页，深页会产生性能压力。

详情和列表只判断 `status=PUBLISHED`，没有同时约束 `auditStatus=APPROVED`。如果状态字段被错误写入，审核拒绝内容仍可能进入公开读路径。

## 5. 删除笔记

删除先校验作者，再逻辑删除评论和笔记，删除详情缓存，并发送评论计数减少与笔记删除事件。删除事件没有本地消息表，MQ 发送失败只记日志，Feed/搜索侧可能永久保留旧内容。

删除评论时，父评论删除会尝试级联删除子评论；应用层顺序不能替代数据库约束，并发回复可能形成孤儿或计数乱序。

## 6. 评论创建

```text
校验笔记已发布
  -> DFA
  -> 校验 parent/reply 归属
  -> 插入评论
  -> 提交后删除评论计数缓存
  -> 发送 COMMENT 计数事件
  -> User Feign 获取昵称
  -> 发送通知事件
```

评论写入和通知放在提交后，避免事务回滚后提前通知；但通知没有本地消息/重试。User Feign 超时会拖慢提交后回调，失败只降级为“某用户”。回复目标在前面校验后又被重新查询，存在二次查询返回 null 导致 NPE 的窗口。

子评论查询没有强制 parent 是一级评论，也没有校验 parent 属于当前公开笔记，创建时的两级限制无法覆盖所有查询路径。

## 7. 敏感词

启动时加载 classpath 静态词库，再从 Redis 动态 Set 加载词并构建 Trie；Redis Pub/Sub 收到 reload 后重新加载。DFA 通过从每个文本位置向后走 Trie 查找命中词。

实现复杂度约为文本长度乘最大词长，不是严格线性；动态词库加载失败时保留静态词库，属于 fail-open。空格/标点清洗和大小写归一化会导致返回命中词与原文位置不完全一致。

## 8. 文件上传

上传接口固定使用 `note` 目录，文件服务检查大小、扩展名/Content-Type 和 magic bytes 后写入 `/data/uploads`，配置映射为 `/uploads/**`。

当前实现把整个文件 `getBytes()` 读入内存后检查头部；并发大文件上传会产生内存压力。文件是本地实例资源，没有所有权绑定、引用清理、共享存储或签名访问控制，多实例部署时可能出现实例间不可见。
