# `deploy/`

用途：存放部署入口、环境编排文件和部署执行资料。

盘点范围：仅列出仓库顶层 `deploy/` 的直接子项，不展开子目录内容。

## 直接子目录

- `docker/` — Docker 部署资料目录。
- `scripts/` — 部署脚本目录。

## 直接文件

- `AUTH-SIMPLIFICATION-EXECUTION-PLAN.md` — 文档；认证简化执行计划。
- `deploy.sh` — 部署执行脚本。
- `ELK-AUTH-REFACTOR-PLAN.md` — 文档；ELK 认证重构计划。
- `machine-a-mysql.yml` — 机器 A 的 MySQL 部署配置。
- `machine-b-middleware.yml` — 机器 B 的中间件部署配置。
- `PRODUCTION-64GB-SINGLE-HOST-PLAN.md` — 文档；生产环境部署计划。
- `STANDARD-ELK-MIGRATION-PLAN.md` — 文档；ELK 迁移计划。
