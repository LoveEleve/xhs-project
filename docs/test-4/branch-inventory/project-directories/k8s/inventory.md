# `k8s/`

用途：存放 Kubernetes 命名空间、工作负载、服务和入口模板配置。

盘点范围：仅列出仓库顶层 `k8s/` 的直接子项，不展开子目录内容。

## 直接子目录

- 无

## 直接文件

- `configmap.yaml` — Kubernetes ConfigMap 配置。
- `deployment-template.yaml` — Kubernetes Deployment 模板。
- `hpa-template.yaml` — Kubernetes HPA 模板。
- `ingress-template.yaml` — Kubernetes Ingress 模板。
- `namespace.yaml` — Kubernetes Namespace 配置。
- `README.md` — 文档；Kubernetes 目录说明。
- `service-template.yaml` — Kubernetes Service 模板。
