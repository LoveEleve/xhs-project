# `root-files/`

盘点范围：记录仓库根目录的直接文件，不包含任何子目录内容。

## 直接文件

- `.gitignore` — 忽略规则配置文件。
- `.gitlab-ci.yml` — GitLab CI 配置文件。
- `.mcp.json` — MCP 配置文件。
- `CLAUDE.md` — 文档；Claude 使用说明。
- `Dockerfile.template` — Docker 模板文件。
- `full-chain-test-v2.sh` — 测试脚本。
- `full-chain-test-v3.sh` — 测试脚本。
- `full-chain-test.sh` — 测试脚本。
- `opencode.json` — Opencode 配置文件。
- `pom.xml` — Maven 聚合构建配置文件。
- `pre-test-init.sh` — 预初始化脚本。
- `setup-firewall.sh` — 防火墙配置脚本。
- `smoke-test.sh` — 冒烟测试脚本。
- `start-all.sh` — 启动脚本。
- `stop-all.sh` — 停止脚本。
