# `config/`

用途：集中存放本地开发、基础设施和中间件配置。

盘点范围：仅列出仓库顶层 `config/` 的直接子项，不展开子目录内容。

## 直接子目录

- `alertmanager/` — 告警管理配置目录。
- `canal/` — Canal 配置目录。
- `deploy-cloud/` — 云部署配置目录。
- `filebeat/` — Filebeat 配置目录。
- `grafana/` — Grafana 配置目录。
- `logstash/` — Logstash 配置目录。
- `mysqld-exporter/` — MySQL 指标采集配置目录。
- `nacos/` — Nacos 配置目录。
- `production-env-config/` — 生产环境配置目录。
- `prometheus/` — Prometheus 配置目录。
- `redis/` — Redis 配置目录。
- `rocketmq/` — RocketMQ 配置目录。
- `sentinel/` — Sentinel 配置目录。
- `skywalking/` — SkyWalking 配置目录。
- `sql/` — SQL 配置和初始化目录。

## 直接文件

- `docker-compose.ai.yml` — Docker Compose 配置文件。
- `docker-compose.yml` — Docker Compose 配置文件。
- `docker-compose.yml.bak-20260812` — 备份文件；备份/生成物。
- `mysql-connector.jar` — JDBC 依赖包二进制文件。
