# `frontend/`

用途：存放项目的前端应用、构建配置和前端文档。

盘点范围：仅列出仓库顶层 `frontend/` 的直接子项，不展开子目录内容。

## 直接子目录

- `docs/` — 文档目录。
- `public/` — 前端公共静态资源目录。
- `src/` — 前端源代码目录。

## 直接文件

- `.gitignore` — 忽略规则配置文件。
- `.oxlintrc.json` — Oxlint 配置文件。
- `index.html` — 前端入口 HTML 文件。
- `package-lock.json` — npm 依赖锁定文件。
- `package.json` — npm 项目配置文件。
- `README.md` — 文档；前端项目说明。
- `tsconfig.app.json` — TypeScript 应用配置文件。
- `tsconfig.json` — TypeScript 配置文件。
- `tsconfig.node.json` — TypeScript Node 配置文件。
- `vite.config.ts` — Vite 构建配置文件。
