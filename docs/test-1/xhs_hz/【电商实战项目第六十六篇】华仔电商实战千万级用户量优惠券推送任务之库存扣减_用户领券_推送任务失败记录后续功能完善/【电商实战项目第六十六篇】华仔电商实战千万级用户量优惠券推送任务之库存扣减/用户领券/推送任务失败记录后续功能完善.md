为了避免访问「**库存扣减**」和「**验证用户是否领券超限**」多次 Redis 请求，所以这里采用 Redis Lua 脚本执行。

Lua 脚本如下所示：

local function stockUserCoupon(stock, limit)

\-- 确定 LIMIT\_BITS 为 8，因为 limit 最大为 255

local LIMIT\_BITS \= 8

\-- 根据 stock 的实际值，计算其对应的二进制表示

\-- 由于 stock 的范围是0\-2，我们可以直接使用它的值

local stockValue \= stock

\-- 位移操作，将 stock 的值左移 LIMIT\_BITS 位

local shifted \= stockValue \* (2 ^ LIMIT\_BITS)

\-- 将 limit 的值与位移后的 stock 值相加

return shifted + limit

end

\-- 获取当前优惠券模板的库存：couponCount

local stock \= tonumber(redis.call('HGET', KEYS\[1\], 'couponCount'))

redis.log(redis.LOG\_DEBUG, "keys1: " .. KEYS\[1\] .." value1: " .. ARGV\[1\])

redis.log(redis.LOG\_DEBUG, "stock: " .. stock)

\-- 判断当前库存是否大于 0

if stock <= 0 then

\-- 库存不足

return stockUserCoupon(1, 0)

end

\-- 获取用户领券次数

local userCouponCount \= tonumber(redis.call('GET', KEYS\[2\]))

redis.log(redis.LOG\_DEBUG, "keys2: " .. KEYS\[2\] .." value2: " .. ARGV\[2\])

\-- 如果用户领券次数不存在，则初始化为 0

if userCouponCount \=\= nil then

userCouponCount \= 0

end

redis.log(redis.LOG\_DEBUG, "userCouponCount: " .. userCouponCount)

\-- 用户领券上限

local perLimitStr \= string.gsub(ARGV\[2\], "\[%s\\"\]", "") -- 移除空格和引号

local perLimit \= tonumber(perLimitStr)

if not perLimit then

return redis.error\_reply("Invalid perLimit: " .. ARGV\[2\])

end

redis.log(redis.LOG\_DEBUG, "perLimit: " .. perLimit)

\-- 判断用户是否已经达到领券上限

if userCouponCount >= perLimit then

redis.log(redis.LOG\_DEBUG, "limit top: " .. userCouponCount .. " perLimit: ".. perLimit)

\-- 用户已经达到领取上限

return stockUserCoupon(2, userCouponCount)

end

\-- 增加用户领券记录

if userCouponCount \=\= 0 then

local expireTimeStr \= string.gsub(ARGV\[1\], "\[%s\\"\]", "") -- 移除空格和引号

local expireTime \= tonumber(expireTimeStr)

redis.log(redis.LOG\_DEBUG, "timestamp: " .. ARGV\[1\].. " expireTime: " .. expireTime)

\-- 如果用户第一次领取，则需要添加过期时间

redis.call('SET', KEYS\[2\], 1)

redis.call('EXPIRE', KEYS\[2\], expireTime)

else

\-- 如果不是第一次领取，直接递增领取次数，过期时间直接使用上一次的

redis.call('INCR', KEYS\[2\])

end

\-- 扣减当前优惠券模板的库存

redis.call('HINCRBY', KEYS\[1\], 'couponCount', -1)

return stockUserCoupon(0, userCouponCount)

可以看到这里将返回的两个参数包装为一个 long 类型的数据，并进行拆分。

这两个参数分别如下：

1.  是否成功：有 3 个参数，0 表示成功，1 表示优惠券已被领取完了，2 表示用户已经达到领取上限。
2.  用户领取次数：初始化为 0，每次领取成功后自增加 1。

如果返回 0,x 表示请求成功，这里的 x 就是目前用户已领取优惠券的次数，会把这个 x 保存到数据库表 [user\_coupon](http://user_coupon%20/) 表的领取次数 [receive\_count](http://receive_count/) 字段中。
