## 一、项目全景概览

### 1.1 项目简介

本项目是一个**社交电商混合型微服务实战项目**，以小红书为蓝本，涵盖用户、社交、商品、订单、支付、优惠券、购物车等核心业务模块，同时深度整合微服务全家桶、缓存体系、搜索引擎、消息队列、分库分表、DevOps 部署、性能压测、监控告警等大厂基础设施。

项目定位为**大厂架构师级别的高并发实战项目**，适合写入简历。

## 七、项目最大亮点总结

1. **完整的交易闭环**：用户 → 商品 → 购物车 → 订单 → 支付 → 优惠券，全链路打通

5. **ShardingSphere 5.5.2 分库分表**：订单 + 优惠券双模块实战
6. **策略+工厂模式**：支付渠道优雅扩展
7. **责任链模式**：优惠券模板创建
8. **完整 DevOps 链路**：Docker → Jenkins → Rancher 一键部署
9. **大厂监控体系**：Prometheus + Grafana + SkyWalking 全链路可观测
10. **GoReplay 流量录制/重放**：真实流量压测
