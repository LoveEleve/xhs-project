### 任务 3：ORDER_COMPENSATION_TOPIC 消费者实现 ─── 🔴 P0

**新建文件**：`my-xhs-order/src/main/java/com/myxhs/order/consumer/OrderCompensationConsumer.java`

```java
package com.myxhs.order.consumer;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.myxhs.order.service.OrderService;
import com.myxhs.common.entity.CompensationMessage;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.apache.rocketmq.spring.annotation.ConsumeMode;
import org.apache.rocketmq.spring.annotation.RocketMQMessageListener;
import org.apache.rocketmq.spring.core.RocketMQListener;
import org.redisson.api.RBucket;
import org.redisson.api.RedissonClient;
import org.springframework.stereotype.Component;

import java.time.Duration;

/**
 * 订单关单补偿消费者
 * 当 L1 延时消息 和 L2 XXL-Job 扫表 都失败时，
 * 发到此 Topic 做最后兜底处理。
 *
 * 消费策略：
 * - 幂等保护：Redis SETNX orderId，防止重复处理
 * - 最大重试 3 次
 * - 3 次失败后写入死信表（人工介入）
 */
@Slf4j
@Component
@RequiredArgsConstructor
@RocketMQMessageListener(
    topic = "ORDER_COMPENSATION_TOPIC",
    consumerGroup = "order-compensation-consumer-group",
    consumeMode = ConsumeMode.CONCURRENTLY,
    consumeThreadMax = 2,
    maxReconsumeTimes = 3
)
public class OrderCompensationConsumer implements RocketMQListener<String> {

    private final OrderService orderService;
    private final RedissonClient redissonClient;
    private final ObjectMapper objectMapper;

    @Override
    public void onMessage(String message) {
        try {
            CompensationMessage cm = objectMapper.readValue(message, CompensationMessage.class);
            String orderId = cm.getOrderId();

            // 1. 幂等保护：同一笔订单只处理一次
            RBucket<String> idempotent = redissonClient.getBucket("compensation:" + orderId);
            if (!idempotent.setIfAbsent("processing", Duration.ofMinutes(10))) {
                log.info("[补偿] 订单已处理或正在处理, orderId={}", orderId);
                return;
            }

            // 2. 执行关单
            orderService.closeTimeoutOrder(orderId);
            log.info("[补偿] 订单关单补偿成功, orderId={}", orderId);

        } catch (Exception e) {
            log.error("[补偿] 关单补偿失败, message={}", message, e);
            throw new RuntimeException(e); // 触发 RocketMQ 重试
        }
    }
}
```

**同时需要在 OrderService 中的关单失败处发送补偿消息**：

```java

    cm.setTimestamp(System.currentTimeMillis());
    rocketMQTemplate.syncSend("ORDER_COMPENSATION_TOPIC",
```

| ES single-node→集群数据重建失败 | 低 | 高 | 先 snapshot 全量备份 → 建新集群 → restore → 切换 alias | snapshot 创建失败时停止 |
| Nacos Config 迁移后服务启动失败 | 中 | 高 | 保留本地 `application.yml` 作为 fallback，`spring.config.import: optional:nacos:` | 启动失败时回退本地配置 |
| MySQL 备份占用生产磁盘 | 中 | 低 | 监控备份目录磁盘使用，自动清理过期备份 | 磁盘使用 > 80% |
