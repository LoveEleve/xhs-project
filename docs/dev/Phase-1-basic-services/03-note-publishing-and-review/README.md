# 笔记发布与审核

> 所属服务：my-xhs-note (9002) | 开发阶段：Phase-1 | 状态：⏳ 待开发

## 功能概要

- 笔记发布（标题50字、正文5000字、图片9张）
- MinIO 文件存储 + CDN
- 笔记状态机（草稿→审核中→已发布/已拒绝→已删除）
- 异步审核（MQ 消费）

## 涉及数据库表

- `t_note` — 笔记表（5000万级）

## 关键技术点

- MinIO 对象存储 + 图片压缩
- 状态机模式管理笔记生命周期
- RocketMQ 异步解耦审核流程
- 逻辑过期防缓存击穿
