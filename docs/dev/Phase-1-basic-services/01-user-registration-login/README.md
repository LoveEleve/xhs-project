# 用户注册登录

> 所属服务：my-xhs-user (9001) | 开发阶段：Phase-1 | 状态：⏳ 待开发

## 功能概要

- 用户注册（手机号/邮箱）
- 用户登录（密码登录）
- JWT 双 Token 机制（Access 30min + Refresh 7d）
- 图形验证码 + 邮箱验证码
- @RateLimit 防暴力破解
- Gateway 统一鉴权

## 涉及数据库表

- `t_user` — 用户表（1000万级）

## 关键技术点

- BCrypt 密码加密
- Redis 存储验证码（5分钟过期）
- 分布式锁保证注册唯一性
- 双 Token 无感刷新
