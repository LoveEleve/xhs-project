# 推荐系统

> 所属服务：my-xhs-search (9007) | 开发阶段：Phase-3 | 状态：⏳ 待开发

## 功能概要

- 5路召回（协同过滤、内容、热门、关注、地理位置）
- 粗排 → 精排（ML 接口预留）→ 重排
- 冷启动策略（新用户/新内容）
- 推荐结果去重与多样性保证

## 涉及数据库表

- `t_user_behavior` — 用户行为日志
- `t_item_feature` — 内容特征表

## 关键技术点

- **5路召回架构**：
  - 协同过滤：基于用户行为的 Item-CF，Redis 矩阵
  - 内容召回：TF-IDF 标签匹配
  - 热门召回：全局热度 Top-N
  - 关注召回：关注用户的最新内容
  - 地理位置召回：同城内容（GeoHash）
- 粗排：多路归并 + 简单打分
- 精排：预留 ML 模型接口（FeatureStore → Model → Score）
- 重排：去重 + 多样性（品类打散）+ 业务规则（已读过滤）
