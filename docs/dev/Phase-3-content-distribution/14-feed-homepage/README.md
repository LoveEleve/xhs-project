# Feed流首页

> 所属服务：my-xhs-home (9005) | 开发阶段：Phase-3 | 状态：⏳ 待开发

## 功能概要

- 首页 Feed 流聚合展示
- 推拉混合模式（普通用户推模式，大V拉模式）
- Feed 流分页（游标分页，非 offset）
- 大V阈值自动判定与扇出优化

## 涉及数据库表

- 无（聚合服务，数据来自其他服务）
- Redis 收件箱：`feed:inbox:{userId}` → ZSet

## 关键技术点

- **推拉混合模型**：
  - 推（写扩散）：普通用户发笔记 → 推送到所有粉丝收件箱
  - 拉（读扩散）：大V发笔记 → 粉丝读取时实时拉取
  - 大V阈值：粉丝数 > 10万切换为拉模式
- 游标分页避免 offset 跳页问题
- Feign 聚合多服务数据（笔记详情+用户信息+计数）
