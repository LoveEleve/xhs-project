# 热搜榜

> 所属服务：my-xhs-search (9007) | 开发阶段：Phase-3 | 状态：⏳ 待开发

## 功能概要

- 实时热搜榜（Top 50）
- 热度计算（搜索量 + 笔记量 + 互动量）
- 时间衰减（近期搜索权重更高）
- 反作弊（异常流量过滤）
- 热搜数据维护（定时清理、人工干预）

## 涉及数据库表

- `t_hot_search` — 热搜快照表

## 关键技术点

- **滑动窗口 + 时间衰减公式**：`Score = Σ(count × e^(-λ×Δt))`
- Redis ZSet 实时排行：`search:hot:realtime` → score=热度
- 反作弊：同IP/同用户频率限制、异常波动检测
- XXL-Job 定时任务：每5分钟快照、每天清理过期数据
- 人工置顶/屏蔽：`search:hot:pinned`、`search:hot:blocked`
