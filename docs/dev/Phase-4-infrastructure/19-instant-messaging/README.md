# 即时通讯 IM

> 所属服务：my-xhs-im (9013) | 开发阶段：Phase-4 | 状态：⏳ 待开发

## 功能概要

- WebSocket 长连接管理
- 私信发送与接收
- 消息已读/未读状态
- 历史消息查询
- 离线消息推送

## 涉及数据库表

- `t_conversation` — 会话表
- `t_message` — 消息表

## 关键技术点

- **WebSocket** 实现双向实时通信（区别于通知的 SSE）
- 消息存储：写扩散（每个参与者一份）vs 读扩散
- 消息 ID 有序：雪花 ID 保证时间有序
- 多端同步：WebSocket + 离线消息拉取
- 消息类型：文本、图片、系统消息

- IM 为什么用 WebSocket 而不是 SSE？
