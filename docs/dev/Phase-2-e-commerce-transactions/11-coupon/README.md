# 优惠券

> 所属服务：my-xhs-coupon (9010) | 开发阶段：Phase-2 | 状态：⏳ 待开发

## 功能概要

- 优惠券创建（运营后台）
- 领取优惠券（防超发）
- 我的优惠券列表
- 下单时优惠券核销
- 优惠券过期自动失效

## 涉及数据库表（分库）

- `t_coupon_template` — 券模板表
- `t_coupon` — 用户券实例表（分库分表）

## 关键技术点

- 分库分表：按 user_id 哈希分库，解决单表数据量大问题
- Redis + Lua 原子扣减库存防超发
- @DistributedLock 防重复领取
- XXL-Job 定时扫描过期券
