# 订单与支付

> 所属服务：my-xhs-order (9011) | 开发阶段：Phase-2 | 状态：⏳ 待开发

## 功能概要

- 创建订单（库存预扣→创建订单→发送支付消息）
- 支付（MockPayService 模拟）
- 取消订单 / 超时自动取消
- 订单快照
- 订单列表查询

## 涉及数据库表（分库）

- `t_order` — 订单主表（分库分表）
- `t_order_item` — 订单明细表
- `t_order_snapshot` — 订单快照表
- `t_local_message` — 本地消息表

## 关键技术点

- **RocketMQ 事务消息 6 步流程**：发送Half→执行本地事务→Commit/Rollback→消费→确认→回查
- 本地消息表兜底方案
- 分库分表：按 buyer_id 哈希
- 延时消息实现超时自动取消（30分钟）
- 订单快照保证历史数据不可变
