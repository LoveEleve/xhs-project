# 库存扣减

> 所属服务：my-xhs-inventory (9009) | 开发阶段：Phase-2 | 状态：⏳ 待开发

## 功能概要

- 库存查询
- 库存扣减（下单时预扣减）
- 库存回补（取消订单/超时未支付）
- 库存分桶（高并发优化）

## 涉及数据库表

- `t_inventory` — 库存主表
- `t_inventory_bucket` — 库存分桶表
- `t_inventory_log` — 库存变更日志

## 关键技术点

- **库存扣减 4 版本演进**：
  1. V1 数据库直接扣减 — 性能差
  2. V2 Redis 预扣减 — 不一致风险
  3. V3 Redis预扣减 + MQ异步落库 — 推荐方案
  4. V4 分桶 + Redis预扣减 — 秒杀场景
- 分布式锁 @DistributedLock 保护库存操作
- RocketMQ 事务消息保证扣减可靠性
