# 性能优化与压测

> 跨服务专题 | 开发阶段：Phase-5 | 状态：⏳ 待开发

## 专题概要

记录项目各阶段的性能优化过程和压测数据，包含调优前后的对比。

## 涉及工具

- JMeter（压测）
- Arthas（在线诊断）
- SkyWalking（链路追踪）
- Prometheus + Grafana（监控）

## 核心内容

| 维度 | 内容 |
|------|------|
| 压测场景设计 | 单接口/混合场景/峰值模型 |
| 性能基线 | 各核心接口的 QPS/RT/P99 基线 |
| 瓶颈定位 | SkyWalking 慢链路 → Arthas 方法级分析 |
| 优化手段 | 缓存优化/SQL优化/JVM调优/连接池调优 |
| 优化效果 | 优化前后数据对比表 |

## 面试高频问题

- 你们项目做过性能优化吗？具体优化了什么？
- 压测怎么做的？压到多少 QPS？
- 遇到过什么性能瓶颈？怎么定位的？
