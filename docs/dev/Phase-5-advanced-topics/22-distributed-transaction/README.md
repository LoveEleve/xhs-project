# 分布式事务

> 跨服务专题 | 开发阶段：Phase-5 | 状态：⏳ 待开发

## 专题概要

本专题聚焦跨服务分布式事务的解决方案，核心场景：下单扣库存、支付扣余额。

## 涉及服务

- my-xhs-order（事务消息发送方）
- my-xhs-inventory（库存扣减消费方）
- my-xhs-coupon（优惠券核销消费方）

## 核心方案

| 方案 | 一致性 | 性能 | 复杂度 | my-xhs选用 |
|------|--------|------|--------|-----------|
| 2PC/XA | 强一致 | 低 | 中 | ❌ |
| TCC | 强一致 | 中 | 高 | ❌ |
| RocketMQ 事务消息 | 最终一致 | 高 | 中 | ✅ 主方案 |
| 本地消息表 | 最终一致 | 高 | 中 | ✅ 兜底方案 |
