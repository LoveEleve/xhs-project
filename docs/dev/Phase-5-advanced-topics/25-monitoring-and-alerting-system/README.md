# 监控告警体系

> 跨服务专题 | 开发阶段：Phase-5 | 状态：⏳ 待开发

## 专题概要

构建完整的可观测性体系：指标监控、链路追踪、日志聚合、告警规则。

## 涉及组件

| 组件 | 职责 |
|------|------|
| Prometheus | 指标采集与存储 |
| Grafana | 可视化面板 |
| SkyWalking | 分布式链路追踪 |
| Loki + Promtail | 日志聚合与查询 |
| AlertManager | 告警通知 |

## 核心内容

| 维度 | 内容 |
|------|------|
| 业务指标 | 订单量、支付成功率、接口QPS/RT |
| 系统指标 | CPU/内存/磁盘/网络/JVM |
| 日志规范 | JSON 结构化日志 + TraceId 关联 |
| 告警规则 | P99 > 500ms、错误率 > 1%、队列积压 > 10000 |
| 大盘设计 | 服务概览 → 单服务详情 → 接口级明细 |

- 日志怎么和链路追踪关联起来的？
- 告警规则怎么设计的？
