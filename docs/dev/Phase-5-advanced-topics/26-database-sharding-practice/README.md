# 分库分表实战

> 跨服务专题 | 开发阶段：Phase-5 | 状态：⏳ 待开发

## 专题概要

本专题聚焦 ShardingSphere 分库分表的完整实践，涉及订单和优惠券两个核心分库场景。

## 涉及服务

- my-xhs-order（4库8表，按 buyer_id 哈希）
- my-xhs-coupon（4库32表，按 user_id 哈希）

## 核心内容

| 维度 | 订单服务 | 优惠券服务 |
|------|----------|-----------|
| 分片键 | buyer_id | user_id |
| 分片算法 | 一致性哈希+虚拟节点 | user_id % 32 |
| 库数×表数 | 4库 × 8表/库 | 4库 × 8表/库 |
| 数据量 | 10亿订单 | 10亿用户券 |
| 读写分离 | ShardingSphere主从路由 | ShardingSphere主从路由 |
| 主键策略 | 雪花ID | 雪花ID |

## 重点覆盖

- ShardingSphere YAML 配置详解
- 自定义分片算法实现
- 分库分表后的跨库 JOIN 问题
- 分库分表后的排序分页问题
- 数据迁移方案（停机迁移 vs 双写迁移）
- 扩容方案（4库→8库）

## 面试高频问题

- 分库分表怎么选分片键？为什么选 user_id 而不是 order_id？
- 分库分表后全局排序怎么做？
- 分库分表后扩容怎么处理？数据迁移方案？
- 跨库 JOIN 问题怎么解决？
