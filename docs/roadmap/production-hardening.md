# 生产化加固作战图（2026-09-17 版）

> 覆盖范围：用户提出的 9 大方向（高并发/调优/RPC/MySQL HA/网关/日志/监控/全链路/多活）
> + 已识别的工程债 + 面试材料轨道。**每条都有现状/目标/验收证据/工作量/优先级**。
> 原则：真做、真测、真演练；深度优先于广度；所有数字带环境口径。

## 资源约束（先摆清楚）
- 单机：16 核 / 62G（当前可用 ~12G）/ 磁盘 38G；15 服务已占 ~7.5G。
- 双 zone / Dubbo 试点需要**额外实例**：按 512m/实例规划，一轮最多加 3-4 个；大动作错峰执行。
- 所有"多活"结论按**同城双活仿真**口径；不宣称异地/生产规模。

## 执行纪律
1. 每项开工前：先出"验收标准"；结束时必须有**可复现命令/报告**。
2. 所有性能数字带环境口径（单机 16C/62G、本地网络）。
3. 动运行中服务：先看 `scripts/restart-service.sh`；改包必重启（fat-jar 懒加载坑）。
4. 每完成一项：提交报告 + 更新 `docs/interview` 对应题与简历口径。
