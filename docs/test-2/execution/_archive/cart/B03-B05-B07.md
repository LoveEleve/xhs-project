# B03/B05/B07 — 购物车操作

## B05: PUT /api/cart/check-all — 全选/取消全选

### ASCII 流转图
```
[curl] → Gateway:19000 → cart:19008
  → CartController.checkAll(X-User-Id=10001, ?checked=true)
  → CartService.checkAll()
     └ Redis:16381 → 遍历 cart hash 设所有 item.checked
```

### curl
```bash
curl -s -X PUT "http://localhost:19000/api/cart/check-all?checked=true" \
  -H "Authorization: Bearer $TOKEN" -H "X-User-Id: 10001"
```

### 七层验证

| 层 | 实际 | 状态 |
|------|------|:--:|
| HTTP | 200 | ✅ |
| Redis | 16381 cart hash checked 状态变更 | ✅ |
| Prometheus | cart actuator 指标 | ✅ |
| SkyWalking | Gateway X-Trace-Id 贯穿 | ✅ |

## B03: DELETE /api/cart/{skuId} — 删除购物车项

### ASCII 流转图
```
[curl] → Gateway:19000 → cart:19008
  → CartController.deleteCartItem(X-User-Id=10001, /skuId)
  → CartService.removeItem()
     └ Redis:16381 HDEL myxhs:cart:{userId}:items {skuId}
```

### 业务逻辑
必须先 B01 加购 → B03 删除 → 验证 list 中已无此 SKU。

### curl
```bash
# 先加购
curl -s -X POST "http://localhost:19000/api/cart/add" \
  -H "Authorization: Bearer $TOKEN" -H "X-User-Id: 10001" \
  -d '{"skuId":2085530413171785729,"quantity":1}'

# 再删除
curl -s -X DELETE "http://localhost:19000/api/cart/2085530413171785729" \
  -H "Authorization: Bearer $TOKEN" -H "X-User-Id: 10001"
```

| 层 | 实际 | 状态 |
|------|------|:--:|
| HTTP | 200 | ✅ |
| Redis | list 验证：SKU 已移除 | ✅ |
