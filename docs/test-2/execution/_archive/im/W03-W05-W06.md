# W03 — 消息记录

`GET /api/im/messages/{peerId}` | JWT required

## ASCII 流转图

```
[curl] → Gateway:19000 → im:19014
  → ImController.getMessages(X-User-Id=10001, /messages/10002)
  → ChatService.getMessageList(MyBatis Page)
     └ MySQL:13306 my_xhs_im.t_chat_message
        SELECT WHERE (sender_id=10001 AND receiver_id=10002)
                   OR (sender_id=10002 AND receiver_id=10001)
        ORDER BY created_at ASC
```

## 业务逻辑

分页查询与指定用户的双向聊天记录，按发送时间正序。支持游标/页数分页。

## curl

```bash
curl -s "http://localhost:19000/api/im/messages/10002" \
  -H "Authorization: Bearer $TOKEN" -H "X-User-Id: 10001"
```

# online-count — 在线人数

`GET /api/im/online-count` | X-Admin-Call required

## ASCII 流转图

```
[curl] → Gateway:19000 → im:19014
  → ImController.getOnlineCount(X-Admin-Call)
  → OnlineRouteService.getServerId()
     └ 返回 {serverId: "uuid", localOnline: 0}
```

## curl

```bash
curl -s "http://localhost:19000/api/im/online-count" \
  -H "Authorization: Bearer $TOKEN" -H "X-Admin-Call: my-xhs-admin-token-2026"
# → {"code":200,"data":{"serverId":"6a6e8c41","localOnline":0}}
```

| 层 | 实际 | 状态 |
|------|------|:--:|
| HTTP | 200, serverId+localOnline | ✅ |
| SkyWalking | traceId=69352615ca934d1d8a90fcfcc5793948 | ✅ |

## 踩坑

| 问题 | 根因 | 解决 |
|------|------|------|
| 403 "无权访问" | IM 编译的 application.yml 中 ADMIN_TOKEN 默认值为空（源码已修正但未重新编译） | `mvn package -pl my-xhs-im` 重新编译 |
