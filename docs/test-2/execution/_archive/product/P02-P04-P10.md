# P02 — 修改 SPU

`PUT /api/product/spu/{spuId}` | X-Admin-Call required

## ASCII 流转图

```
[curl] → Gateway:19000 → product:19006
  → ProductController.updateSpu(spuId=2085352027803664385, X-Admin-Call, body:SpuUpdateRequest)
  → SpuService.updateSpu()
     ├ spuMapper.selectById(spuId)   [MySQL:13307 my_xhs_product.t_spu]
     ├ LambdaUpdateWrapper → 只 update 传入非空字段(name/categoryId/brandId/description/images)
     └ spuMapper.update(wrapper)     [UPDATE MySQL]
```

## 业务逻辑

LambdaUpdateWrapper 部分更新 SPU 字段——只改传入的，不改不动的列。无 log 输出（设计如此）、无 Redis 缓存失效、无 MQ。
