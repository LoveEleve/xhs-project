```

```

## 九、踩坑速查

| 问题 | 原因 | 解决 |
|------|------|------|
| Gateway HMAC 403 | 端点不在白名单 | grep hmac-white-list，加路径，重编 GW |
| 服务重启后不响应 | 僵尸进程 | `fuser -k {port}/tcp` 精准杀 |
| TOKEN 跨 Bash 丢失 | 每次 Bash 是新 shell | `echo $TOKEN > /tmp/test_token.txt` |
| YAML DuplicateKeyException | 插入的 key 已存在 | grep 确认无重复再编辑 |
| MySQL 查空 | 同端口不同库(13307有3库) | 确认 `库名.表名` |
| ES .withJson() 报错 | ES Client 8.x 用 .document(map) | 返回 Map 非 JSON String |
| Map.of() NPE | DB 列有 null 值 | 用 HashMap + getOrDefault |
| @Profile("dev") 端点 404 | 默认无 dev profile | `--spring.profiles.active=dev` |
| DTO 字段名猜错 | 凭直觉不用源码 | grep DTO 类确认字段名 |
| 覆盖表过期 | 测完忘记更新 | 每批立即同步 §二 + execution/README |
| Redis key 格式错误 | ASCII 图写的 key 是猜测的 | grep RedisKeyConstants 源码确认完整 key |
| 中文参数 curl 400 | curl 不编码 | `--data-urlencode "prefix=测试"` |
